## 二、钻探编录表转换方式

1、分成行和列的索引即可，例如：行是1，列是B，那么就代表：第0行，第1列，(Excel是从1行开始，列是从A开始， 对应JSON都是0行，0列开始)

2、Excel底部的“钻孔名称"为键key。
