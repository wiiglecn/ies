#### 1.2.5 底图不可用告警文案枚举（200 + warnings[]，不返 5xx）

与接口文档 §7.9 逐条一致：上传 IO 异常 / >50MB / 空文件 / 落盘失败 / URL 下载失败·超时·DNS / 响应为空 / 内容超限 / 重定向 >3 次 / SSRF 命中回环或协议非法（统一文案"base_map_url 校验未通过（详见网关日志）"，**不泄露拒因**）。CAD 端收到 `warnings[]` 后必须 `acedAlert` / `acutPrintf` 显式告知（禁止仅日志）。

#### 1.2.6 SSRF 口径（冻结，V1.6 已落定）

仅 http/https；禁回环 `127.0.0.0/8` + `::1`（`socket.getaddrinfo` 解析后 `ipaddress.is_loopback`）；私网/公网默认全放行（`SSRF_DEFAULT_ALLOW_ALL=True`）；`--ssrf-whitelist-cidr` 传入后只放行白名单；重定向最多 3 次逐跳校验 + 累计字节限流 50MB；超时 30s；**插件端不联网**。

### 1.3 HTTP 请求语义（双 Content-Type 生效规则）

三接口共用 `_resolve_form_json(field, required)`：

```
borehole_data / plan_base / section_params：
  1) 优先 JSON body（request.get_json(silent=True)）
  2) body 无 → request.form 同名字符串 json.loads 兜底（multipart）
  3) 非法 JSON → ValueError → HTTP 400（"<field> invalid JSON in body/form"）
auto_zoom：
  request.form.get("auto_zoom") 优先，无则 JSON body 取，默认 true（bool，无需 json.loads）
底图字段（base_map 文件 / base_map_url 字符串）：
  仅从 request.files / request.form 读取 —— JSON body 提交时 form 为空
  （该路径的处置即 P0-3，见 §1.4；处置结果需同步接口文档）
```

### 1.4 P0-3 修复口径（`base_map_url` JSON body 静默忽略漏洞）

| 方案 | 内容 | 优点 | 缺点 |
| --- | --- | --- | --- |
| A | 网关侧校验：`application/json` 请求体中**出现 `base_map_url`（或 `base_map`）键即返 400**，文案明示"底图字段仅支持 multipart/form-data" | ① 与接口文档 §8.1"只有调用方式错误才 400"的既有分类完全自洽（用错 Content-Type 本就是调用方式错误）；② 实现约 5 行、不动解析主路径；③ 保留"底图一律 multipart"的单一心智模型，契约不分叉；④ 彻底消灭静默路径，符合"告警必达"精神（显式拒绝优于静默吞掉） | 调用方传 URL 也必须用 multipart（略不便） |

### 2.3 关键算法伪代码

#### 2.3.1 BASEPOINT 扣减矩阵 —— ⚠️ 勘误版（决策点 D6，二选一）

**基线缺陷**：详设 §5.3.1 公式 `M = mT·mR·mS·T(basePt)·T(−basePt)` 中 `T(basePt)·T(−basePt) ≡ I`（AcGe 列向量约定下先 −B 后 +B 相互抵消），**按字面实现等于不做基点校正**，V1.5 错位问题原样保留。

**几何推导（正确目标）**：块参照原生落点 `W = ptInsert + R(θ)·s·(P − B)`；配准意图 `q = T + s·R(θ)·P`。两式联立得**修正后的插入点**：

```
ptInsert' = T + s·R(θ)·B        （B = 源 DWG 模型空间 BASEPOINT）
```

**方案甲（推荐）——插入点前修正，ApplyPlotScale 零特判**：

```cpp
// ImportBaseMap 内、调用 ImportDwgAsBlock 之前：
AcGePoint3d ptInsert(c.insertX, c.insertY, 0.0);
if (c.hasBasePoint) {
    // 修正：ptInsert' = insert + R(rotation)·scale·BASEPOINT
    double cs = cos(c.rotation), sn = sin(c.rotation);
    ptInsert.x += c.scale * ( cs * c.sourceBasePoint.x - sn * c.sourceBasePoint.y);
    ptInsert.y += c.scale * ( sn * c.sourceBasePoint.x + cs * c.sourceBasePoint.y);
    // 日志：[CAD INFO] BASEPOINT=(x,y) ≠ 原点，插入点已前修正 (Δx, Δy)
}
AcDbObjectId blkDefId = ImportDwgAsBlock(dwgPath, ptInsert, kBaseMapBlock,
                                         c.scale, c.rotation, c.layer.GetString());
// ApplyPlotScale 内：所有实体（含底图块参照）统一 transformBy(m)，无任何特判分支
```

**方案乙——保留详设结构（ApplyPlotScale 阶段后补偿）**：导入按 `ptInsert=T` 原样，`BuildImportMatrix` 冻结为**补偿平移矩阵**（而非抵消公式）：

```cpp
// BuildImportMatrix 勘误版：返回对块参照额外施加的补偿平移 D = s·R(θ)·B
AcGeMatrix3d CCreatePlanView::BuildImportMatrix(const AcGePoint3d& ptInsert, double dScale,
                                                double dRotation, const AcGePoint3d& sourceBasePoint)
{
    double cs = cos(dRotation), sn = sin(dRotation);
    AcGeVector3d v(dScale * (cs * sourceBasePoint.x - sn * sourceBasePoint.y),
                   dScale * (sn * sourceBasePoint.x + cs * sourceBasePoint.y), 0.0);
    return AcGeMatrix3d::translation(v);   // mImport = T(s·R(θ)·B)
}
// ApplyPlotScale 缩放循环内（识别 kBaseMapBlock 且 m_baseCfg.hasBasePoint）：
//     mTotal = m * mImport;  pRef->transformBy(mTotal);  continue;
// 其余实体 transformBy(m)
```

两方案数学等价（甲 = 乙的平移并入插入点）；**推荐甲**（改动更小、消除 ApplyPlotScale 特判分支与 `m_baseCfg.sourceInsertPoint` 依赖、错位排查时导入日志一行可见）。T14a 用例两方案都必须实测。**无论选哪版，PM 需派单修订详设 §5.3.1/§5.4。**

#### 2.3.4 `ParseRegistration()` 数组解析流程（P0-6）

```
ParseRegistration(bm, cfg):
    reg = bm["registration"]; 非对象 → return false（走手动参数）
    src = reg["source_points"]; tgt = reg["target_points"]
    src/tgt 非数组 → WARN "结构无效"; return false
    nSrc != nTgt 或 nSrc ∉ [1,2] → WARN "点数不匹配或超范围"; return false
    遍历 src 每个元素 ps:
        ps 非数组 或 GetArraySize(ps) != 2 → WARN "源点 i 不是 [x,y] 数组"; return false
        sx=ps[0], sy=ps[1]; 任一非 cJSON_IsNumber → WARN; return false
        cfg.srcPts[i] = (sx.valuedouble, sy.valuedouble)
    遍历 tgt 同上 → cfg.tgtPts[i]
    cfg.regPtCount = nSrc; cfg.hasRegistration = true; return true
```

```python
        try: data = _http_get_with_redirects(url, URL_TIMEOUT)
        except ValueError as e:
            "ssrf denied"/"only http(s)" → return None, ["底图未被采用：base_map_url 校验未通过（详见网关日志）"]  # 不泄露拒因
            其它（大小/重定向）→ return None, [f"底图未被采用：{e}"]
        except Exception as e: → return None, ["底图未被采用：URL 下载失败（类型：消息）"]
        data 空 / 落盘失败 → 对应告警
        return f"support/底图/{name}", []
    return None, []                                         # 未提供 → 流程一

# ---------- /api/draw/plan（骨架） ----------
@app.route("/api/draw/plan", methods=["POST"])
def draw_plan():
    # ① 锁外必填校验
    try: bh = _resolve_form_json("borehole_data", required=True); pb = _resolve_form_json("plan_base")
    except ValueError as e: return 400 {"status":"error","message":str(e)}
    # ①' P0-3 校验（方案 A，见 §3.4；拍板后实施）
    # ② 锁外底图获取
    try: dwg, dwg_warnings = _save_base_map()
    except ValueError as e: return 400 {"status":"error","message":str(e)}
    warnings = list(dwg_warnings)
    degraded_to = "process1_no_basemap" if dwg is None else None
    # ③ 锁内：落盘 + 调 CAD（300s）
    with _lock:
        _write_json(BOREHOLE_FILE, _translate_borehole(bh))
        if pb is not None:
            cfg = dict(pb); if dwg: cfg.setdefault("base_map", {})["dwg"] = dwg   # 网关回写底图路径
            _write_json(PLAN_BASE_FILE, cfg)                # 英文 key 原样
        elif dwg: _write_json(PLAN_BASE_FILE, {"base_map": {"dwg": dwg}})
        else:     _remove_if_exists(PLAN_BASE_FILE)         # 流程一：不留上次配置
        try: result = _call_cad(VIEW_ROUTES["plan"], timeout=PLAN_TIMEOUT)
        except requests.exceptions.Timeout:
            return 504 {"status":"error","message":"plan view timed out (300s)",
                        "warnings":warnings,"degraded_to":degraded_to}
    # ④ auto_zoom 锁外（30s，异常吞掉）
    # ⑤ 永远返回四字段
    return 200 {"status":"success","results":{"plan":result},"warnings":warnings,"degraded_to":degraded_to}
```

`/api/draw/column`、`/api/draw/section` 骨架同详设 §9.3（解析 → `_lock` 内翻译落盘 → `_call_cad(120s)` → auto_zoom → `{"status","results"}`），无底图逻辑。
