## 1. TL;DR

**需规有问题，性质是"概念表述不清 + 与理正作业流程的路由不一致 + 需求内部自相矛盾 + 关键约束缺失"，需要回炉。**

- **不是推倒重来**：整体框架（三图分离、一次性无状态、底图作背景+布孔、降级容错）是对的，方向与理正一致。
- **必须改（P0，5 条）**：① "不重绘" vs "重画粗线" 表述冲突；② 未处理"底图原拟建线 + 新画粗线"双线重叠；③ 坐标系默认行为未写明（会导致孔偏）；④ "不访问外网" 与 "URL 下载底图" 直接矛盾；⑤ "无状态" 与固定落盘路径的单项目假设未声明。
- **建议改（P1，6 条）**：R9/R10 优先级过高、JSON 兜底价值存疑、术语"底图初始化"定义失准、出图比例未表态、图例"及层数"与范围不符、客户资料约定太弱。
- **一句话定性**：本插件在理正"底图作背景 + 布孔"之上，**多做了"提取拟建轮廓并重画粗线+影子"这一步**——这既非理正做法，也未被业务前提（底图已含拟建）证成，是本轮争议的根因。

## 2. 理正真实作业流程 vs 本需规 对照表

> 理正流程来源：理正《软件使用方法》/《软件操作》公开文档——"生成平面图前……如想把平面图布置到已有底图上，**需先打开已有底图，然后执行'底图初始化'命令来设定初始化图形参数和坐标的转换等**，最后（在图上成批）布置勘探点和剖线"，并需设定**出图比例（比例因子）**与**实体遮盖效果**（多来源交叉印证，见文末）。

| 环节 | 理正怎么做 | 本需规怎么写 | 差距 / 是否合理 |
| --- | --- | --- | --- |
| **底图初始化** | 打开已有底图 → 执行"底图初始化"：设定**图形参数（出图比例/比例因子）** + **坐标转换（配准）** + **遮盖效果**；理正按图层管理底图要素 | 术语表定义为"底图导入后设定坐标基准、**出图比例**、图层匹配；本需求对应'导入+对齐'"（需求文档 L365），但正文与实现**只认一个"拟建层"、完全没有"出图比例"** | **定义与做法脱节**：术语表提了"出图比例"，正文却没这条需求 → 应明确本次做/不做 |
| **坐标对齐** | 在"底图初始化"里做坐标转换 | R7/FR-2.1~2.5：两点配准（平移+旋转+均匀缩放）+ 手动参数 + 非法回退 | **方向一致，合理**；但**默认行为未写明**（见 P0-3） |
| **布孔** | 底图上按坐标/里程**布置勘探点**（可单个"新增勘探点"或成批） | R8/已实现：按编录数据 `X坐标(m)/Y坐标(m)` 在"勘察点方案"层插入钻孔图块 | **一致，合理**（代码核验：CreatePlanView.cpp L107/L115 取 X/Y 坐标作插入点） |
| **拟建建筑** | 拟建轮廓**由底图自带**，理正**不提取、不重画**，仅作背景 | R9/FR-3.1/3.2：**从底图图层提取轮廓 → 重画为粗线** + 影子 | **路由不一致**：本插件比理正多做了"提取+重画"。这半句价值仅剩"视觉区分"，应降为可选叠加（见第 4 章） |
| **已有建筑** | 随底图呈现 | 保留底图、整体置灰（FR-1.3） | **合理**（细化） |
| **出图层次** | 底图为背景，成果要素叠加其上 | BR-7/FR-5.3：底图→影子→拟建→钻孔→图例 | **合理**（细化，无冲突） |
| **出图比例** | "底图初始化"必设（如 1:500 选比例因子 0.5） | **全文无此需求** | **缺失**：本次做不做必须表态（见 P1-4） |
| **图例** | 有图例，含已有/拟建建筑符号 | R11 + 代码现有图例块 `PMYyjz`/`PMXnjz`，文字"已有建筑物**及层数**"/"拟建建筑物**及层数**" | **内部不一致**：图例承诺"层数"，正文却把"建筑名称/层数标注"划到范围外（见 P1-5） |
| **底图类型** | 支持加载既有底图（含线路专业底图） | 仅支持 DWG（N5）| 用户转述提到"支持插入光栅扫描图"，**本需规未支持** → 需与客户确认是否要（见待确认清单） |

## 4. 建议的范围调整结论

| 事项 | 结论 | 理由 |
| --- | --- | --- |
| **R9/R10（提取+重画+影子）是否保留** | **保留能力，但降级为可选叠加，默认不启用** | 底图已含拟建、理正不重画（对照表）。默认行为应对齐理正：**底图原样背景 + 布孔 + 图例**。提取重画仅在客户明确要"拟建视觉突出"时启用 |
| **优先级如何定** | FR-3.1/3.2（提取+重画）→ **P1**；FR-3.4（视觉可区分）→ **P0**（可用"置灰底图"达成）；FR-4.x（影子）→ **P2**；R11 图例 → **P0**；R6 底图导入/置灰 → **P0**；R7 对齐 → **P0** | 与理正一致项（导入/对齐/置灰/布孔/图例）为 P0；"比理正多做"项降级 |
| **JSON 兜底 `proposed_buildings` 去留** | **删除**；如需保留，仅作**开发调试**，不列入验收、不对客户暴露 | 底图已含拟建 → 人工录坐标成本极高、几乎不会用；保留会增加实现与验收负担 |
| **出图比例是否纳入** | **本版不纳入**，范围边界明确写"不做"，列为后续 | 理正必设但本插件无此概念；本次应以"底图背景+布孔"对齐理正最小可用流程，比例留待后续（否则拉长工期） |
