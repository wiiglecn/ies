## 1. 背景与问题陈述

### 1.1 项目整体目标

本项目是一个运行于 AutoCAD（2005 / 2007）的岩土勘察出图插件。**项目的整体目标：以钻孔编录数据为唯一数据源，一键生成三类勘察成果图**：

| 成果图 | 用途 | 现状 |
| --- | --- | --- |
| **平面图**（勘探点平面布置图） | 在场地底图上标注钻孔位置、编号及环境要素，表达勘察工作布置 | 已实现"布孔 + 图例"；**缺底图环节**（本次新增） |
| **柱状图**（钻孔柱状图） | 单孔成果：岩性分层、标贯、水位、孔径、坐标等逐孔成图 | **已实现** |
| **剖面图**（工程地质剖面图） | 沿剖面线展示各钻孔地层对比、尖灭、水位、标贯/静探 | **已实现** |

### 1.2 已实现能力（代码反推，需求基线）

### 1.3 本次要解决的问题（平面图）

当前平面图缺少底图环节，导致：

1. **无底图导入**：出图时没有场地平面底图，需人工在 AutoCAD 中粘贴或描画委托方图纸；
2. **无拟建建筑绘制**：拟建建筑物（区别于已有建筑的成果要素）没有轮廓与"影子"（阴影）效果；
3. **坐标错位靠人工**：底图坐标系与钻孔坐标系不一致时，对齐完全依赖人工。

### 1.4 业务前提（已确认）

| # | 前提 | 确认状态 |
| --- | --- | --- |
| 1 | **底图由委托方（甲方）直接提供**，是现成的场地现状总平面 DWG，含已有建筑、道路等现状要素 | 已确认 |
| 2 | **底图中包含拟建建筑轮廓**，总平面图惯例画在专门图层（如"拟建建筑"层） | 已确认 |
| 3 | 底图与钻孔坐标原则上同为当地坐标系、单位米；不一致时需对齐 | 已确认 |
| 4 | 钻孔数据以 `project/钻探编录表.json` 为准（三图共用） | 已确认 |
| 5 | 底图未配置/文件缺失时，平面图出图**降级为仅布孔+图例**，不影响现有流程 | 已确认（硬性兼容要求） |

## 2. 目标与范围

### 2.1 目标

1. **整体目标不变**：以 `钻探编录表.json` 为唯一数据源，一键生成平面图、柱状图、剖面图三图；
2. **平面图补齐底图环节**：委托方底图（自动导入、可置灰）+ 拟建建筑（粗线轮廓 + 影子）+ 钻孔 + 图例，一次命令全部生成；
3. **底图自动对齐**：通过**两点配准**自动计算平移/旋转/缩放，替代人工校准；无配准数据时支持手动参数；
4. **拟建轮廓自动提取**：拟建建筑轮廓**从底图 DWG 按图层自动提取**，无需人工描图或另行提供坐标数据；
5. **完全兼容**：新能力均可选；不配置任何新数据时平面图行为与现状一致；**柱状图、剖面图不受任何影响**。

### 2.2 范围内（本次要做）

| 模块 | 内容 |
| --- | --- |
| 底图导入 | 配置 DWG 路径 → 导入为整体块，纳入独立图层，可整体置灰（淡化） |
| 底图对齐 | 手动 insert/scale/rotation 参数 + **两点配准**（2 对已知点自动求四参数） |
| 拟建建筑 | **从底图指定图层提取闭合轮廓**绘制粗线；JSON 轮廓为兜底方案 |
| 影子（阴影） | 拟建轮廓整体平移 (dx, dy) + 浅灰 SOLID 填充，可开关、可调偏移 |
| 平面图集成 | 与布孔、图例同一事务"一键生成"；重复执行可整体重建（幂等） |
| 容错 | 任何新配置缺失/失败 → 打印告警并降级，不阻断布孔与图例 |
| 网关 | HTTP 网关 `/api/draw` 支持透传 `plan_base` 配置落盘 |
| **回归保护** | 柱状图、剖面图现有功能**不做任何修改**，纳入回归验证 |

### 2.3 范围外（本次不做，列为后续扩展）

| 项 | 说明 |
| --- | --- |
| XREF 外部参照 | 底图以外部参照引用（含重载、更新同步） |
| 多点/仿射配准 | 3 点以上最小二乘、不等比/非正交变形配准 |
| 交互式配准 | 在 AutoCAD 内鼠标拾取配准点（现为 JSON 配置点对） |
| 拟建实体类型扩展 | 旧式多段线、直线/圆弧组合轮廓、块内拟建实体提取 |
| 图面装饰 | 图框、指北针、比例尺、拟建建筑名称/层数标注 |
| 分幅出图 | 多张底图并存、按线路分幅 |
| 底图图层映射 | 将底图内已有建筑/道路按规范图层自动归类置灰 |
| 柱状图/剖面图增强 | 如剖面自动连层优化、柱状图多孔批量分页等（不在本次范围） |

## 3. 干系人与使用场景

### 3.1 干系人

| 角色 | 职责 | 与本功能的关系 |
| --- | --- | --- |
| 勘察技术人员 | 出图操作者 | 导入数据、配置 `plan_base.json`、执行三图命令、校核成果 |
| 委托方（甲方） | 提供底图 DWG | 底图数据（含拟建建筑轮廓）的提供方 |
| 设计/勘察负责人 | 成果审核 | 验收三图完整性与正确性 |

### 3.2 典型使用场景

**场景 1 · 三图出图（现状流程）**
> 导入 `钻探编录表.json` → 分别执行"平面图 / 柱状图 / 剖面图"命令 → 得到三类成果图（本次不改变柱状图、剖面图行为）。

**场景 2 · 平面图带底图出图（本次新增）**
> 委托方提供 `05阳光幸福里总平面规划图104(1).dwg`（建筑轮廓在"0-规划建筑"图层，客户截图确认）→ 配置 `plan_base.json`（底图路径 + 拟建图层 + 阴影参数）→ 执行"平面图"→ 得到：置灰底图 + 拟建建筑粗线轮廓与影子 + 钻孔 + 图例。

**场景 3 · 底图与钻孔坐标不一致（本次新增）**
> 底图未落当地坐标或单位不同 → 取底图上两个已知点（如建筑角点）及钻孔坐标系下对应坐标，填入 `registration` → 出图时自动配准对齐。

**场景 4 · 底图缺失/未配置（兼容现状）**
> 无底图资料或 `plan_base.json` 未提供 → 平面图仅布孔 + 图例，与现状一致，无报错。

### 4.7 网关支持（一次性无状态接口，V2.2 修订）

> **V2.2 修订**：接口由"项目制多接口"（V2.1）改回并定型为**一次性无状态调用**：**系统不记录任何项目信息**。三个生成接口分开，数据随调用携带——
> - **生成柱状图**：调用时携带勘探数据；
> - **生成剖面图**：调用时携带勘探数据（+ 可选剖面参数）；
> - **生成平面图**：调用时携带勘探数据 + **底图**（实际 DWG 文件上传，或底图文件的可访问链接，二选一）+ 可选平面图配置。
>
> 每次调用独立完成落盘与出图，调用结束不保留项目状态。**接口约定：路径中不放参数，参数一律放在请求参数（form / query / body）中。**

| --- | --- | --- |

## 6. 业务规则与约束

| 编号 | 规则 |
| --- | --- |
| BR-1 | 所有坐标单位为**米**；钻孔坐标以 `钻探编录表.json` 的 `X坐标(m)/Y坐标(m)` 为唯一来源（三图共用） |

| BR-8 | 影子颜色 253（浅灰）、拟建轮廓线宽按打印标定（默认 0.75） |

### 7.2 新增配置：`project/plan_base.json`（全部可选）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| base_map.dwg | string | 委托方底图 DWG 路径（相对插件目录）；空/不存在 → 跳过底图 |
| base_map.insert_x / insert_y | number | 手动对齐：插入点（米），默认 0,0 |
| base_map.scale | number | 手动对齐：比例，默认 1.0 |
| base_map.rotation | number | 手动对齐：旋转角（弧度），默认 0.0 |
| base_map.layer | string | 底图所在图层，默认"底图-现状" |
| base_map.dim | bool | 是否置灰（默认 false） |
| base_map.proposed_layer | string | 拟建建筑轮廓所在底图图层名；配置后优先从底图提取 |
| base_map.registration.source_points | array | 两点配准源点（底图坐标），1~2 个 `[x,y]` |
| base_map.registration.target_points | array | 与源点对应的钻孔坐标点，数量一致 |
| shadow.dx / shadow.dy | number | 影子偏移（米），默认 1.5 / -1.5 |
| shadow.enabled | bool | 是否画影子，默认 true |
| proposed_buildings[] | array | **兜底**拟建轮廓：name、floors、outline（≥3 点闭合 `{x,y}`） |

### 7.3 配置示例（典型）

```json
{
  "base_map": {
    "dwg": "support/底图/05阳光幸福里总平面规划图104(1).dwg",
    "dim": true,
    "proposed_layer": "0-规划建筑",
    "registration": {
      "source_points": [[2747350.0, 36524890.0], [2747650.0, 36524890.0]],
      "target_points": [[2747450.0, 36524990.0], [2747750.0, 36524990.0]]
    }
  },
  "shadow": { "dx": 1.5, "dy": -1.5, "enabled": true }
}
```

> 示例取值为真实项目（阳光幸福里）底图截图确认（2026-10-13）：底图 `05阳光幸福里总平面规划图104(1).dwg`，建筑轮廓图层 **`0-规划建筑`**；底图坐标与钻孔同为当地坐标系，默认即对齐。实际项目最少仅需 `base_map.dwg`（导入底图）；加 `proposed_layer` 即启用拟建+阴影；加 `registration` 即启用自动配准。

## 8. 验收标准

### 8.1 三图整体回归（本次不得破坏）

| # | 验收项 | 判定标准 |
| --- | --- | --- |
| R1 | 柱状图 | 执行柱状图命令，逐孔成图与改造前一致（模板、字段、花纹、标贯统计） |
| R2 | 剖面图 | 用网关格式的正确参数（`剖面组/勘察组` + 编录表内真实孔号）执行剖面图命令，验证剖面布置、标尺、地层连线、尖灭、花纹输出正常；并修复/更新 Debug 测试参数键名不一致问题 |
| R3 | 平面图（无底图配置） | 仅布孔+图例，与现有出图完全一致、无报错 |

### 8.2 平面图新增功能

| # | 验收项 | 判定标准 |
| --- | --- | --- |
| 1 | 底图导入 | 配置底图路径后一键出图，底图以整体块出现在"底图-现状"层，位置符合配置（手动或配准） |
| 2 | 自动对齐 | 底图与钻孔坐标不一致时，配置 2 对配准点即可自动对齐，钻孔准确落在底图对应位置 |
| 3 | 拟建建筑 | 配置拟建图层后，底图内拟建建筑轮廓被提取为粗线多边形（独立图层），与底图要素吻合 |
| 4 | 影子 | 拟建建筑右下方有浅灰影子（可开关、可调偏移），与轮廓形状一致 |
| 5 | 视觉层次 | 打印预览：底图最底 → 阴影 → 拟建轮廓 → 钻孔 → 图例最顶 |
| 6 | 兼容现状 | 不配置任何新数据时，平面图行为与现状完全一致 |
| 7 | 重建 | 同一数据重复生成两次，图形一致、无残留 |
| 8 | 容错 | 底图缺失、配准非法、提取失败均告警并降级，不中断出图 |
| 9 | 双版本 | AutoCAD 2005 / 2007 均编译运行正常 |
| 10 | 网关 | 一次性调用链路正确：生成柱状图/剖面图携带勘探数据、生成平面图携带勘探数据+底图（文件或链接）均能落盘与出图；无项目信息残留 |
