## 1. 背景与问题陈述

### 1.1 项目整体目标

本项目是一个运行于 AutoCAD（2005 / 2007）的岩土勘察出图插件。**项目的整体目标：以钻孔编录数据为唯一数据源，一键生成三类勘察成果图**：

| 成果图 | 用途 | 现状 |
| --- | --- | --- |
| **平面图**（勘探点平面布置图） | 在场地底图上标注钻孔位置、编号及环境要素，表达勘察工作布置 | 已实现"布孔 + 图例"；**缺底图环节**（本次新增） |
| **柱状图**（钻孔柱状图） | 单孔成果：岩性分层、标贯、水位、孔径、坐标等逐孔成图 | **已实现** |
| **剖面图**（工程地质剖面图） | 沿剖面线展示各钻孔地层对比、尖灭、水位、标贯/静探 | **已实现** |

### 1.3 本次要解决的问题（平面图）

当前平面图缺少底图环节，导致：

1. **无底图导入**：出图时没有场地平面底图，需人工在 AutoCAD 中粘贴或描画委托方图纸；
2. **无出图比例**：无法按勘察出图惯例（如 1:500 / 1:1000）设定**成图比例**，据此缩放底图并作为图面比例尺 / 标注的依据；
3. **坐标错位靠人工**：底图坐标系与钻孔坐标系不一致时，对齐完全依赖人工。

### 1.4 业务前提（已确认）

| # | 前提 | 确认状态 |
| --- | --- | --- |
| 1 | **底图由委托方（甲方）直接提供**，是现成的场地现状总平面 DWG，含已有建筑、道路等现状要素 | 已确认 |
| 2 | **底图中包含拟建建筑轮廓**，总平面图惯例画在专门图层（如"拟建建筑"层）；**本版不提取、不重画**，随底图背景一并呈现 | 已确认 |
| 3 | 底图与钻孔坐标原则上同为当地坐标系、单位米；不一致时需对齐 | 已确认 |
| 4 | 钻孔数据以 `project/钻探编录表.json` 为准（三图共用） | 已确认 |
| 5 | 未提供底图或底图文件缺失时，平面图按**流程一（委托方无底图）**正常出图（自动布孔 + 标注 + 图例），不影响其他流程 | 已确认（硬性要求） |

## 2. 目标与范围

### 2.1 目标

1. **整体目标不变**：以 `钻探编录表.json` 为唯一数据源，一键生成平面图、柱状图、剖面图三图；
2. **平面图两种委托情形并列**：平面图按委托方是否提供底图，分**两条地位对等的主流程**——**流程一（委托方没有底图）**只提交勘探数据 → 布孔 + 标注 + 图例；**流程二（委托方有底图）**提交勘探数据 + 底图（+ 配置）→ 成果叠加底图；二者**共用同一个"生成平面图"入口**（一步式，不拆命令，区别仅在是否携带底图与 `plan_base`）；
3. **平面图补齐底图环节（流程二能力）**：委托方底图（自动导入、可置灰）+ 出图比例 + 钻孔 + 图例，一次命令全部生成；
4. **底图自动对齐**：通过**两点配准**自动计算平移/旋转/缩放，替代人工校准；无配准数据时支持手动参数；
5. **出图比例（两条流程均适用）**：支持设定成图比例（如 1:500），据此计算比例因子对**整体成图**统一缩放，并作为图面比例尺/标注的依据；流程一仅跳过"底图导入 + 底图对齐"两步，不跳过本比例；
6. **完全兼容**：新能力均可选；不提供底图与新增配置时平面图按流程一正常出图；**柱状图、剖面图不受任何影响**。

### 2.2 范围内（本次要做）

| 模块 | 内容 |
| --- | --- |
| 两种委托情形 | **流程一（委托方没有底图）**：仅提交勘探数据 → 自动布孔 + 标注 + 图例；**流程二（委托方有底图）**：提交勘探数据 + 底图（+ 配置）→ 成果叠加底图；二者**共用同一个"生成平面图"入口**（一步式，不拆命令，区别仅在是否携带底图与 `plan_base`） |
| 底图导入【流程二】 | 配置 DWG 路径 → 导入为整体块，纳入独立图层，可整体置灰（淡化） |
| 底图对齐【流程二】 | 手动 insert/scale/rotation 参数 + **两点配准**（2 对已知点自动求四参数）；**默认按"底图坐标即钻孔坐标"处理，不施加变换** |
| 出图比例 | 设定成图比例（如 1:500），计算比例因子对**整体成图**统一缩放，作为图面比例尺/标注依据（**流程一、流程二均适用**，详见 §4.3） |
| 图例 | 沿用现有图例（钻孔、已有/拟建建筑说明符号、剖面线）；建筑图例文字按 §4.4 结论调整（不含"及层数"） |
| 平面图集成 | 与布孔、图例同一事务"一键生成"；重复执行可整体重建（幂等） |
| 容错 | 任何新配置未提供/失败 → 打印告警，**按流程一（无底图）继续出图**，不阻断布孔与图例 |
| 网关 | HTTP 网关 `/api/draw` 支持透传 `plan_base` 配置落盘 |
| **回归保护** | 柱状图、剖面图现有功能**不做任何修改**，纳入回归验证 |

> 范围说明：本版**不重画底图内容**（不再提取/重画拟建轮廓），底图原样作为背景导入，故**不存在轮廓双线重叠问题**（原评审 P0-2 自动消解）。

### 2.4 底图制作要求 / 图层最小规范

> 为避免导入/对齐失败，委托方（或制图方）提供的底图建议满足以下最小规范：

| 要求 | 说明 |
| --- | --- |
| 坐标系与单位 | 底图与钻孔**同一坐标系、单位为米**；不一致时须提供两组对应配准点坐标（见 §4.2） |
| 底图比例/单位 | 底图按真实坐标 1:1 建模（模型空间 1 单位 = 1 米）。**单位/坐标系不一致**走**对齐参数**（`registration` / 手动 `scale`）；**出图比例**仅定**成图比例**，不做单位/坐标系换算，二者分离（见 §4.3、BR-5） |
| DWG 版本 | 建议为 **AutoCAD 2004 及以下格式**，确保 AutoCAD 2005 / 2007 可打开 |
| 层数信息 | 明确定义底图是否包含建筑层数标注（影响图例文字，见 §4.4） |
| 底图类型 | 本版**仅支持 DWG**；**扫描光栅图（栅格图像）本版不支持** |
| 拟建/已有建筑 | 由底图自带并在图面呈现；本版**不提取、不重画**，因此**不存在轮廓双线重叠问题** |

### 3.2 典型使用场景

**"生成平面图"的两条并列主流程（地位对等，共用同一入口）**

> 两条流程**同一个"生成平面图"命令**、**一步式**：底图与配置随调用一次性提交，区别仅在于是否携带底图文件与 `plan_base` 配置。**不拆成两个命令。**

- **流程一 · 委托方没有底图**：只提交勘探数据 → 生成平面图（自动布孔 + 标注 + 图例）；出图比例 `plot_scale` 照样适用（缩放钻孔落点 + 图例）。
- **流程二 · 委托方有底图**：提交勘探数据 + 底图（DWG 文件或可访问链接）+ 可选配置（出图比例/对齐）→ 成果叠加在底图之上；出图比例 `plot_scale` 适用（缩放底图几何 + 钻孔 + 图例）。

| 对比项 | 流程一（委托方没有底图） | 流程二（委托方有底图） |
| --- | --- | --- |
| 提交内容 | 勘探数据 | 勘探数据 + 底图 + 可选配置 |
| 底图导入 | 跳过 | 导入底图 DWG |
| 底图对齐 | 跳过 | 按 §4.2 对齐 |
| 出图比例 `plot_scale` | **适用**（缩放钻孔落点 + 图例） | **适用**（缩放底图几何 + 钻孔 + 图例） |
| 成果构成 | 钻孔（布孔 + 标注）+ 图例 | 底图 + 钻孔 + 图例 |
| 出图入口 | 同为"生成平面图"（同一命令） | 同为"生成平面图"（同一命令） |

**场景 1 · 三图出图**
> 导入 `钻探编录表.json` → 分别执行"平面图 / 柱状图 / 剖面图"命令 → 得到三类成果图（本次不改变柱状图、剖面图行为）。其中平面图按委托方是否提供底图，走上面**两条并列主流程**之一。

**场景 2 · 流程二：底图与钻孔坐标一致（本次新增）**
> 委托方提供 `05阳光幸福里总平面规划图104(1).dwg`，底图与钻孔同为当地坐标系 → 配置 `plan_base.json`（底图路径 + 出图比例，可选置灰）→ 执行"平面图"→ 得到：置灰底图 + 钻孔 + 图例，并按出图比例缩放。

**场景 3 · 流程二：底图与钻孔坐标不一致（本次新增）**
> 底图未落当地坐标或单位不同 → 取底图上两个已知点（如建筑角点）及钻孔坐标系下对应坐标，填入 `registration` → 出图时自动配准对齐。

**场景 4 · 流程一：委托方没有底图（本次并列的正式流程）**
> 无底图资料或 `plan_base.json` 未提供底图 → 平面图正常生成：自动布孔 + 标注 + 图例（底图-现状层为空）；若配置了 `plot_scale`，钻孔落点与图例照常统一缩放。无报错，与底图有无无关。

### 4.3 出图比例（底图初始化）

> **语义定义**：出图比例指**成图比例**（如 1:500、1:1000），即图纸上 1 单位对应实地 N 单位。系统据此计算比例因子 `k = 1000 / N`（N 为比例分母，500 表示 1:500；约定底图按 1 单位 = 1 米建模）（**暂定，待客户确认**），对**整体成图（底图几何 + 钻孔落点 + 成果要素）按同一比例因子、绕同一基准统一缩放**，**保证底图与钻孔不错位**（二者经同一变换）；钻孔的 X/Y 坐标标注文字仍显示真实坐标值。缩放后成果图在该比例下可正确打印，并作为**图面比例尺 / 标注**的依据。
>
> **与 §4.2 对齐 `scale` 的区别（务必区分，勿混为一谈）**：
> - **对齐 `scale`（§4.2）**：用于**坐标对齐**——是两点配准 / 手动参数得到的缩放修正系数，目的是消除底图与钻孔的**坐标系 / 单位差异**，使二者落在同一坐标；同坐标系且单位均为米时其值为 1.0。
> - **出图比例（本节）**：用于**成图输出**——是打印 / 图面比例，与坐标对齐无关，对**整体成图**统一缩放并作为比例尺依据。
>
> **两条流程均适用（关键，勿写错）**：出图比例与**有无底图无关**——
> - **流程二（委托方有底图）**：缩放"底图几何 + 钻孔 + 图例"；
> - **流程一（委托方没有底图）**：底图-现状层为空，仍缩放"钻孔落点 + 图例"，**成果层照常统一缩放**。
>
> 流程一**只跳过"底图导入 + 底图对齐"两步，不跳过出图比例**；仅当未配置 `plot_scale` 时才不施加缩放。

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR-3.1 | 支持配置**出图比例**（如 500 表示 1:500）；**未配置时不施加出图比例缩放**（流程一、流程二一致），配置后按比例出图 | P0 |
| FR-3.2 | 依据出图比例计算比例因子 `k = 1000 / N`（**暂定，待客户确认**），对**整体成图（底图几何 + 钻孔落点 + 成果要素）按同一比例因子、绕同一基准统一缩放**（保证底图与钻孔不错位）——**流程二**缩放底图几何 + 钻孔 + 图例，**流程一**缩放钻孔落点 + 图例；缩放结果作为图面比例尺 / 标注的依据；日志输出所用比例与比例因子 | P0 |
| FR-3.3 | 出图比例与 §4.2 对齐参数互不干扰：先按对齐参数完成坐标对齐，再按出图比例缩放（两者串联、顺序固定） | P0 |

> ⚠️ **待客户确认（暂定）**：出图比例本版按**"对整体成图统一缩放"**实现——底图几何、钻孔落点、成果要素经同一变换，故底图与钻孔不错位；比例因子 `k = 1000 / N`，约定底图 1 单位 = 1 米。以上均为**暂定，待客户确认**；若客户改为"仅作图面比例尺依据、不改几何"，则以客户确认为准。

## 8. 验收标准

### 8.1 三图整体回归（本次不得破坏）

| # | 验收项 | 判定标准 |
| --- | --- | --- |
| R1 | 柱状图 | 执行柱状图命令，逐孔成图与改造前一致（模板、字段、花纹、标贯统计） |
| R2 | 剖面图 | 用网关格式的正确参数（`剖面组/勘察组` + 编录表内真实孔号）执行剖面图命令，验证剖面布置、标尺、地层连线、尖灭、花纹输出正常；并修复/更新 Debug 测试参数键名不一致问题 |
| R3 | 平面图（流程一 · 委托方无底图） | 未提供底图与新增配置时，按流程一出图：自动布孔 + 标注 + 图例，无报错；未配置 `plot_scale` 时不缩放（与现有出图一致） |

### 8.2 平面图新增功能

| # | 验收项 | 判定标准 |
| --- | --- | --- |
| 1 | 底图导入 | 配置底图路径后一键出图，底图以整体块出现在"底图-现状"层，位置符合配置（手动或配准） |
| 2 | 自动对齐 | 底图与钻孔坐标不一致时，配置 2 对配准点即可自动对齐，钻孔准确落在底图对应位置；未配置对齐时按"同一坐标系"默认导入并在日志说明 |
| 3 | 出图比例 | 设定出图比例（如 1:500）后，**整体成图（底图几何 + 钻孔落点 + 成果要素）按同一比例因子统一缩放、底图与钻孔不错位**，成果图按该比例可正确打印，图面比例尺/标注与其一致 |
| 4 | 视觉层次 | 打印预览：底图最底 → 钻孔 → 图例最顶 |
| 5 | 兼容现状 | 不配置任何新数据时，平面图行为与现状完全一致 |
| 6 | 重建 | 同一数据重复生成两次，图形一致、无残留 |
| 7 | 容错 | 底图未提供、配准非法、出图比例非法均告警，**按流程一（无底图）继续出图**，不中断布孔与图例 |
| 8 | 双版本 | AutoCAD 2005 / 2007 均编译运行正常 |
| 9 | 网关 | 一次性调用链路正确：生成柱状图/剖面图携带勘探数据、生成平面图携带勘探数据+底图（文件或链接）均能落盘与出图；无项目信息残留 |
| 10 | 边界 · 底图 DWG 版本过高 | 底图 DWG 版本超过目标 CAD（AutoCAD 2005 / 2007）可读版本时，给出"版本过高 / 无法读取"的明确提示，跳过底图导入并**按流程一继续出图**，不中断布孔与图例 |
| 11 | 边界 · `base_map_url` 下载失败 / 超时 | 网关端下载 `base_map_url` 失败或超时时，返回明确错误提示（含失败原因 / 超时），平面图**按流程一继续出图**，不中断；日志记录失败原因 |
| 12 | 边界 · 并发调用 | 并发调用时系统**串行处理**（锁内串行），各调用互不干扰、不产生数据 / 图纸串扰，结果与串行调用一致 |

## 9. 术语表

| 术语 | 说明 |
| --- | --- |
| 勘察三图 | 平面图（勘探点平面布置图）、柱状图（钻孔柱状图）、剖面图（工程地质剖面图），插件三大成果图 |
| 勘探点平面布置图 | 在场地底图上标注钻孔位置的平面成果图 |
| 流程一（委托方没有底图） | 平面图的一种正式生成流程：只提交勘探数据 → 自动布孔 + 标注 + 图例；与"流程二"**地位对等**，**共用同一个"生成平面图"入口**（一步式，不拆命令），区别仅在是否携带底图与 `plan_base` |
| 流程二（委托方有底图） | 平面图的另一种正式生成流程：提交勘探数据 + 底图（+ 出图比例/对齐配置）→ 成果叠加在底图之上 |
| 底图 | 委托方提供的场地现状总平面 DWG，作为平面图的工作底图（含现状与拟建要素） |
| 底图初始化 | 理正术语，指打开底图后**设定出图比例（比例因子）、坐标转换（配准）与图层匹配**；本需求实现其中"**出图比例 + 坐标对齐**"两项（图层自动匹配不在本版范围） |
| 出图比例 | 底图初始化时设定的**成图比例**（如 1:500、1:1000）；据此计算比例因子 `k = 1000 / N`（暂定，待客户确认）对**整体成图**统一缩放并作为图面比例尺/标注的依据。**区别于**底图对齐用的缩放 `scale`（见 §4.3） |
| 拟建建筑 | 底图中待建建筑轮廓（区别于已有建筑）；**本版不提取、不重画**，随底图背景呈现 |
| 两点配准 | 以底图两点与钻孔坐标两点对应，自动计算平移/旋转/缩放的对齐方法 |
| 三图命令 | 插件命令：SLPlanView（平面图）、SLColumnView（柱状图）、SLSectionView（剖面图） |
