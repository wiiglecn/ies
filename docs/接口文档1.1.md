# CAD 勘察出图插件 接口文档

| 项目 | 内容 |
| --- | --- |
| 文档名称 | CAD 勘察出图插件（KsExploration.arx）内嵌 HTTP 服务接口文档 |
| 版本 | V1.1 |
| 日期 | 2026-10-21 |
| 适用 | AutoCAD 2007 + KsExploration.arx |

---

## 1. 连接信息

| 项 | 值 |
| --- | --- |
| 地址 | `http://localhost:7100` |
| 启动 | AutoCAD 命令行 `(arxload "KsExploration.arx")` → `SLINIT` |
| 编码 | UTF-8，JSON 无 BOM |
| 字段命名 | 全中文业务字段名 |

---

## 2. 接口清单

| # | 端点 | 说明 | 超时 |
| --- | --- | --- | --- |
| 1 | `POST /ai/feature/create_column_view` | 柱状图 | 120s |
| 2 | `POST /ai/feature/create_section_view` | 剖面图 | 180s |
| 3 | `POST /ai/feature/create_plan_view` | 平面图 | 300s |

---

## 3. 公共请求字段

三个接口共用：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `borehole_data` | object | **是** | 钻孔数据，key = 孔号，value = 结构化 dict，见 §6 |
| `project_name` | string | **是** | 项目名；落盘文件名前缀 |
| `section_params` | object | 剖面图/平面图必填 | 剖面参数，见 §4 |

---

## 4. `section_params` 结构

```json
{
  "剖面组": [
    {
      "标题": "A-A",
      "水平比例": 500,
      "垂直比例": 100,
      "勘察组": ["ZK1", "ZK2", "ZK3"],
      "零标高": 208.55,
      "开挖标高": 202.55
    }
  ]
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `标题` | string | 否 | 剖面编号（如 `A-A`），用于表头和分页 |
| `水平比例` / `垂直比例` | number | 否 | 比例分母，缺省 500 / 100 |
| `勘察组` | string[] | **是** | 本剖面经过的孔号，顺序即出图顺序 |
| `零标高` | number | 否 | 零标高对应的绝对标高（m）；未提供则取最高孔口高程 |
| `开挖标高` | number | 否 | 基础底设计标高（m）；未提供则不画基础底设计标高线 |

---

## 5. 响应

统一格式：

```json
{
  "status": "success"
}
```

错误时：

```json
{
  "status": "error",
  "message": "错误描述"
}
```

## 6. `borehole_data` 数据格式

### 6.1 顶层结构

```json
{
  "ZK1": { "钻孔编号": "ZK1", ... },
  "ZK2": { "钻孔编号": "ZK2", ... }
}
```

### 6.2 单孔字段

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `钻孔编号` | string | **是** | 钻孔编号 |
| `X坐标(m)` | number | 平面必填 | 大地坐标 X |
| `Y坐标(m)` | number | 平面必填 | 大地坐标 Y |
| `孔口高程(m)` | number | **是** | 孔口高程 (m) |
| `终孔深度(m)` | number | 柱状必填 | 终孔深度 (m) |
| `钻孔类型` | string | 建议 | 钻孔类型（"技术孔" / "鉴别孔" / "工程观测孔"） |
| `工程名称` | string | 建议 | 工程名称 |
| `公司名称` | string | 否 | 公司名称 |
| `工程地点` | string | 否 | 工程地点 |
| `开孔日期` | string | 否 | 开孔日期 |
| `终孔日期` | string | 否 | 终孔日期 |
| `初见水位(m)` | string | 否 | 初见水位，无则 `""` |
| `稳定水位(m)` | string | 否 | 稳定水位，无则 `""` |
| `地层列表` | array | 柱状必填 | 地层列表，见 §6.3 |

### 6.3 `地层列表[]` 字段

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `地层编号` | string | **是** | 地层编号 |
| `进底起(m)` | number | **是** | 层顶深度 |
| `到底深度(m)` | number | **是** | 层底深度 |
| `地层名称` | string | **是** | 用于匹配填充图案 |
| `颜色` | string | 否 | 颜色 |
| `状态` | string | 否 | 状态（可塑 / 中风化等） |
| `密实度` | string | 否 | 密实度 |
| `湿度` | string | 否 | 湿度 |
| `描述内容` | string | 否 | 描述栏 |
| `取样(土、水)样` | object | 否 | `{ "编号": "", "取样深度": "" }` |
| `原位测试` | object | 否 | `{ "类型": "标贯", "起(m)": "", "止(m)": "", "杆长(m)": "", "锤击数(击)": "" }` |

## 7. curl 示例

### 7.1 柱状图

```bash
curl -X POST http://localhost:7100/ai/feature/create_column_view \
  -H "Content-Type: application/json; charset=utf-8" \
  -d '{
    "project_name": "阳光幸福里",
    "borehole_data": {
      "ZK1": { "钻孔编号": "ZK1", "孔口高程(m)": 206.05, "终孔深度(m)": 19.2, "地层列表": [...] }
    }
  }'
```

### 7.2 剖面图

```bash
curl -X POST http://localhost:7100/ai/feature/create_section_view \
  -H "Content-Type: application/json; charset=utf-8" \
  -d '{
    "project_name": "阳光幸福里",
    "borehole_data": {
      "ZK1": { ... },
      "ZK2": { ... },
      "ZK3": { ... }
    },
    "section_params": {
      "剖面组": [
        {
          "标题": "A-A",
          "水平比例": 500,
          "垂直比例": 100,
          "勘察组": ["ZK1", "ZK2", "ZK3"],
          "零标高": 208.55,
          "开挖标高": 202.55
```

## 8. 落盘文件

写盘到 `ARX_DIR/project/`：

```
project/{项目名}-钻探编录表.json
project/{项目名}-剖面图参数.json
```

`{项目名}` 经净化：剔除 `\ / : * ? " < > |` 与控制字符、去首尾空白、截断 64 字符。

---

## 9. 错误排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 连接拒绝 | CAD 没起 / ARX 没加载 / 没 `SLINIT` | 重启 CAD，`arxload`，`SLINIT` |
| HTTP 200 但没出图 | 缺 `borehole_data` / `project_name` | 检查请求体 |
| 柱图无填充 | `地层名称` 未在 `pat_define.json` 配置 | 补图案映射 |
