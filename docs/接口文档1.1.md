# CAD 勘察出图插件 接口文档

| 项目 | 内容 |
| --- | --- |
| 文档名称 | CAD 勘察出图插件（KsExploration.arx）对外接口文档 |
| 版本 | V1.1 |
| 日期 | 2026-10-21 |
| 适用 | AutoCAD 2007 + 勘察三图（平面图 / 柱状图 / 剖面图）出图 |

---

## 1. 架构

```
业务系统
   │  HTTP，application/json 或 multipart/form-data
   ▼
Flask 网关 cad_server/draw_gateway.py （端口 7200）
   │  落盘 project/{项目名}-*.json
   │  转发 HTTP
   ▼
AutoCAD 2007 + KsExploration.arx （端口 7100）
   │  读落盘文件 → 出图
```

---

## 2. 通用约定

| 项 | 约定 |
| --- | --- |
| 字符编码 | UTF-8，JSON 无 BOM |
| 字段命名 | 全中文业务字段名 |
| 无状态 | 每次调用独立落盘，后一次覆盖前一次 |
| 单项目 / 单 CAD 实例 | 同一时刻仅服务一个项目、一个 CAD 实例 |
| 并发 | 网关串行，并发请求排队 |

### 2.1 提交方式

两种 Content-Type，网关自动识别：

| Content-Type | 适用场景 | 解析规则 |
| --- | --- | --- |
| `application/json; charset=utf-8` | 纯数据提交（无底图文件） | 从 JSON body 取字段 |
| `multipart/form-data` | 需上传底图文件 | body 取不到则从 form 字段读字符串并 `json.loads` 解析 |

---

## 3. 接口清单

| # | 接口 | 说明 | 超时 |
| --- | --- | --- | --- |
| 1 | `POST /api/draw/column` | 柱状图 | 120s |
| 2 | `POST /api/draw/section` | 剖面图 | 180s |
| 3 | `POST /api/draw/plan` | 平面图（含底图导入） | 300s |

---

## 4. 公共请求字段

三个接口共用以下字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `borehole_data` | object | **是** | 钻孔数据，二维数组 JSON，见 §7 |
| `project_name` | string | 否 | 项目名；缺省时取第一孔 `工程名称` |
| `auto_zoom` | bool | 否 | 出图后自动全图缩放，默认 `true` |

---

## 5. `POST /api/draw/column` — 柱状图

### 5.1 请求

```
POST http://<gateway>:7200/api/draw/column
Content-Type: application/json; charset=utf-8
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `borehole_data` | object | **是** | 钻孔数据二维数组 |
| `project_name` | string | 否 | 项目名 |
| `auto_zoom` | bool | 否 | 默认 true |

### 5.2 响应

```json
{
  "status": "success",
  "results": { "column": { "status": "success" } }
}
```

---

## 6. `POST /api/draw/section` — 剖面图

### 6.1 请求

```
POST http://<gateway>:7200/api/draw/section
Content-Type: application/json; charset=utf-8
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `borehole_data` | object | **是** | 钻孔数据二维数组 |
| `section_params` | object | **是** | 剖面参数，见 §6.2 |
| `project_name` | string | 否 | 项目名 |
| `auto_zoom` | bool | 否 | 默认 true |

### 6.2 `section_params` 结构

```json
{
  "剖面组": [
    {
      "标题": "A-A",
      "水平比例": 500,
      "垂直比例": 100,
      "勘察组": ["ZK1", "ZK2", "ZK3"],
      "零标高": 208.55,
      "开挖标高": 202.55
    }
  ]
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `标题` | string | 否 | 剖面编号（如 `A-A`），用于表头和分页 |
| `水平比例` / `垂直比例` | number | 否 | 比例分母，缺省 500 / 100 |
| `勘察组` | string[] | **是** | 本剖面经过的孔号，顺序即出图顺序 |
| `零标高` | number | 否 | 零标高对应的绝对标高（m）；未提供则取最高孔口高程 |
| `开挖标高` | number | 否 | 基础底设计标高（m）；未提供则不画基础底设计标高线 |

### 6.3 响应

```json
{
  "status": "success",
  "results": { "section": { "status": "success" } }
}
```

---

## 7. `POST /api/draw/plan` — 平面图

### 7.1 请求

```
POST http://<gateway>:7200/api/draw/plan
Content-Type: multipart/form-data        # 有底图时必须用这个
   或   application/json; charset=utf-8  # 无底图时可用这个
```

| 字段 | 类型 | 必填 | 提交位置 | 说明 |
| --- | --- | --- | --- | --- |
| `borehole_data` | object | **是** | JSON body 或 form | 钻孔数据二维数组 |
| `section_params` | object | 否 | JSON body 或 form | 剖面参数；提供时画剖切位置线 |
| `base_map` | file | 有条件 | **仅 form** | 底图 DWG 文件上传，与 `base_map_url` 二选一 |
| `base_map_url` | string | 有条件 | **仅 form** | 底图 DWG URL 下载，与 `base_map` 二选一 |
| `project_name` | string | 否 | JSON body 或 form | 项目名 |
| `auto_zoom` | bool | 否 | JSON body 或 form | 默认 true |

> **底图字段仅支持 multipart/form-data**：`base_map` / `base_map_url` 只从 `request.form` / `request.files` 读取。用 `application/json` 传底图键会返回 400。

### 7.2 响应

永远包含以下四个字段：

```json
{
  "status": "success",
  "results": { "plan": { "status": "success" } },
  "warnings": [],
  "degraded_to": "process1_no_basemap"
}
```

| 字段 | 说明 |
| --- | --- |
| `status` | `"success"` / `"error"` |
| `results` | `{"plan": <CAD 返回体>}` |
| `warnings` | 告警数组；底图不可用时文案以"底图未被采用："开头 |
| `degraded_to` | `null` = 有底图模式；`"process1_no_basemap"` = 无底图模式 |

## 8. `borehole_data` 数据格式

### 8.1 顶层结构

```json
{
  "ZK1": [[row_0], [row_1], ...],
  "ZK2": [[row_0], [row_1], ...]
}
```

| 约束 | 规则 |
| --- | --- |
| 顶层 | object，key = 孔号字符串 |
| 每个 value | 二维数组，每行是一个 list |
| 行数 | 每孔 ≥ 7 行 |
| 编码 | UTF-8，JSON 无 BOM |

### 8.2 单孔行义表

| 行索引 | 内容 | 关键列 |
| --- | --- | --- |
| Row 0 | 公司名称 | col 0 = 公司名 |
| Row 1 | 表名 + 页码 | col 0 = 表名；col 18 = 页码 |
| Row 2 | 工程基本信息 | col 1 = 工程名称；col 11 = 孔口高程；col 14 = 钻孔类型；col 18 = 终孔深度 |
| Row 3 | 工程地点 + 开孔日期 | col 1 = 工程地点；col 11 = 开孔日期；col 14 = 初见水位 |
| Row 4 | 孔号 + 坐标 | col 1 = 孔号；col 4 = 测量 X（北）；col 9 = 测量 Y（东）；col 11 = 终孔日期；col 14 = 稳定水位 |
| Row 5 | 地层表头起首 | col 0 = "地层编号" |
| Row 6 | 地层字段表头 | col 1 = "自"；col 2 = "至"；col 3 = "地层名称"；col 4 = "颜色"；col 5 = "状态"；col 6 = "密实度"；col 7 = "湿度"；col 8 = "成分及其他"；col 13 = "编号"；col 14 = "取样深度"；col 15 = "类型"；col 16 = "起(m)"；col 17 = "止(m)"；col 18 = "杆长(m)"；col 19 = "锤击数(击)" |
| Row 7~N | 每个地层一行 | 按 Row 6 表头列偏移取字段值 |

## 9. 状态码与错误处理

| 状态码 | 触发条件 | 响应 |
| --- | --- | --- |
| 200 | 正常 | `{status, results, ...}` |
| 400 | 调用方式错误 | `{status:"error", message:...}` |
| 504 | 超时 | `{status:"error", message:"...timed out"}` |
| 5xx | 内部异常 | 透传 |

### 9.1 400 错误明细

| 触发 | message |
| --- | --- |
| `borehole_data` 缺失或非法 JSON | `missing required field: borehole_data` / `borehole_data invalid JSON` |
| `section_params` 非法 JSON | `section_params invalid JSON` |
| `base_map` 与 `base_map_url` 同传 | `base_map 与 base_map_url 互斥，二选一` |
| `base_map_url` 用 JSON body 提交 | `base_map / base_map_url 仅支持 multipart/form-data 提交` |

## 10. curl 示例

### 10.1 柱状图

```bash
curl -X POST http://<gateway>:7200/api/draw/column \
  -H "Content-Type: application/json; charset=utf-8" \
  -d '{
    "borehole_data": { "ZK1": [[...]] },
    "project_name": "阳光幸福里",
    "auto_zoom": true
  }'
```

### 10.2 剖面图

```bash
curl -X POST http://<gateway>:7200/api/draw/section \
  -H "Content-Type: application/json; charset=utf-8" \
  -d '{
    "borehole_data": { "ZK1": [[...]] },
    "project_name": "阳光幸福里",
    "section_params": {
      "剖面组": [
        {
          "标题": "A-A",
          "水平比例": 500,
          "垂直比例": 100,
          "勘察组": ["ZK1","ZK2","ZK3"],
          "零标高": 208.55,
          "开挖标高": 202.55
        }
      ]
    },
    "auto_zoom": true
  }'
```

### 10.3 平面图（无底图）

```bash
curl -X POST http://<gateway>:7200/api/draw/plan \
  -H "Content-Type: application/json; charset=utf-8" \
  -d '{
    "borehole_data": { "ZK1": [[...]] },
    "project_name": "阳光幸福里",
    "section_params": { "剖面组": [...] },
    "auto_zoom": true
  }'
```

### 10.4 平面图（URL 底图）

```bash
curl -X POST http://<gateway>:7200/api/draw/plan \
  -F 'borehole_data={"ZK1":[[...]]};type=application/json' \
  -F 'base_map_url=https://example.com/xxx.dwg' \
  -F 'section_params={"剖面组":[...]};type=application/json'
```

## 11. 落盘文件

网关落盘到 `ARX_DIR/project/`：

```
project/{项目名}-钻探编录表.json
project/{项目名}-剖面图参数.json
```

`{项目名}` 经净化：剔除 `\ / : * ? " < > |` 与控制字符、去首尾空白、截断 64 字符。
