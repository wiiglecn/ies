# CAD 勘察出图插件 接口文档

| 项目 | 内容 |
| --- | --- |
| 文档名称 | CAD 勘察出图插件（KsExploration.arx）内嵌 HTTP 服务接口文档 |
| 版本 | V1.3 |
| 日期 | 2026-10-27 |
| 适用 | AutoCAD 2007 + KsExploration.arx |

> **V1.3 变更（2026-10-27）**
> 单孔新增字段 `工程编号`（与 `工程名称` 同级）：柱状图表头「工程编号」格取此值；不传则该格留空，其余行为不变。

> **V1.2 变更（2026-10-22）**
> 1. `boreholeData` 由「`{孔号: 对象}` 映射」改为**钻孔对象数组** `[{...}, {...}]`，主键统一为 `钻孔编号` 字段；旧的映射形态仍兼容（打 `[7100] WARN`）。
> 2. 请求体顶层字段统一小驼峰：`projectName` / `boreholeData` / `sectionParams`（下划线拼写已废弃，兼容期内可读）。
> 3. 本章为**直连 ARX 7100** 的权威口径；7200 网关（`cad_server/draw_gateway.py`）不再维护。

---

## 1. 连接信息

| 项 | 值 |
| --- | --- |
| 地址 | `http://localhost:7100` |
| 启动 | AutoCAD 命令行 `(arxload "KsExploration.arx")` → `SLINIT` |
| Content-Type | `application/json; charset=utf-8` |
| 编码 | UTF-8，JSON 无 BOM |
| 字段命名 | 请求体顶层小驼峰（`projectName` / `boreholeData` / `sectionParams`）；孔内业务键沿用中文章名 |

---

## 2. 接口清单

| # | 端点 | 说明 | 超时 |
| --- | --- | --- | --- |
| 1 | `POST /ai/feature/create_column_view` | 柱状图 | 120s |
| 2 | `POST /ai/feature/create_section_view` | 剖面图 | 180s |
| 3 | `POST /ai/feature/create_plan_view` | 平面图 | 300s |

---

## 4. `POST /ai/feature/create_section_view` — 剖面图

### 4.1 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `projectName` | string | **是** | 项目名；落盘文件名前缀（旧名 `project_name` 已废弃） |
| `boreholeData` | array | **是** | 钻孔对象数组，见 §6（旧名 `borehole_data` 已废弃） |
| `sectionParams` | object | **是** | 剖面参数，见 §4.2（旧名 `section_params` 已废弃） |

### 4.2 `sectionParams` 参数

```json
{
  "剖面组": [
    {
      "标题": "A-A",
      "水平比例": 500,
      "垂直比例": 100,
      "勘察组": ["ZK1", "ZK2", "ZK3"],
      "零标高": 208.55,
      "开挖标高": 202.55
    }
  ]
}
```

| 字段 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `标题` | string | 否 | 页码编号 | 剖面编号（如 `A-A`），用于表头与图签图名 |
| `水平比例` | number | 否 | 500 | 水平比例分母 |
| `垂直比例` | number | 否 | 100 | 垂直比例分母 |
| `勘察组` | string[] | **是** | — | 本剖面经过的孔号，顺序即出图顺序 |
| `零标高` | number | 否 | 最高孔口高程 | 零标高对应的绝对标高（m） |
| `开挖标高` | number | 否 | 不画 | 基础底设计标高（m）；未提供则不画基础底设计标高线 |

## 6. `boreholeData` 数据格式（钻孔对象数组）

### 6.1 顶层结构

```json
[
  { "钻孔编号": "ZK1", ... },
  { "钻孔编号": "ZK2", ... }
]
```

> **主键**：数组形态下 `钻孔编号` 就是孔的唯一标识（`勘察组` 的孔引用、平面图块名、`boreholeData` 查询全部按它命中），**每孔必填**；缺失的孔打 `[7100] WARN`，块名退化成 `KsHole_<序号>`。

### 6.2 单孔字段

| 字段名 | 类型 | 柱状图必填 | 剖面图必填 | 平面图必填 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `钻孔编号` | string | **是** | **是** | **是** | 钻孔编号；**数组形态下即主键，必须唯一且必填** |
| `孔口高程(m)` | number | **是** | **是** | 建议 | 孔口高程 (m) |
| `终孔深度(m)` | number | **是** | 建议 | — | 终孔深度 (m) |
| `X坐标(m)` | number | — | 建议 | **是** | 大地坐标 X |
| `Y坐标(m)` | number | — | 建议 | **是** | 大地坐标 Y |
| `钻孔类型` | string | 建议 | 建议 | 建议 | "技术孔" / "鉴别孔" / "工程观测孔" |
| `工程名称` | string | 建议 | 建议 | 建议 | 工程名称；剖面图图签栏位取此值 |
| `工程编号` | string | 建议 | 否 | 否 | 工程编号；柱状图表头「工程编号」格取此值 |
| `公司名称` | string | 建议 | 建议 | 否 | 勘察单位全称；剖面图图签「勘察单位」栏取此值 |
| `工程地点` | string | 否 | 否 | 否 | 工程地点 |
| `开孔日期` | string | 否 | 否 | 否 | 开孔日期 |
| `终孔日期` | string | 否 | 否 | 否 | 终孔日期 |
| `初见水位(m)` | string | 否 | 否 | 否 | 无则 `""` |
| `稳定水位(m)` | string | 否 | 否 | 否 | 无则 `""` |
| `地层列表` | array | **是** | **是** | — | 见 §6.3 |

### 6.3 `地层列表[]` 字段

| 字段名 | 类型 | 必填 | 说明 |

| `地层编号` | string | **是** | 地层编号 |
| `进尺自(m)` | number | **是** | 层顶深度（进尺自） |
| `进尺至(m)` | number | **是** | 层底深度（进尺至） |

| `密实度` | string | 否 | 密实度 |
| `湿度` | string | 否 | 湿度 |
| `成分及其他` | string | 否 | 描述栏（成分、成因、状态等） |
| `取岩(土、水)样` | object | 否 | `{ "编号": "", "取样深度": "" }` |
| `原位测试` | object | 否 | `{ "类型": "标贯", "起(m)": "", "止(m)": "", "杆长(m)": "", "锤击数(击)": "" }` |

## 9. 错误排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 连接拒绝 | CAD 没起 / ARX 没加载 / 没 `SLINIT` | 重启 CAD，`arxload`，`SLINIT` |
| HTTP 200 但没出图 | 缺 `boreholeData` / `projectName`，或孔缺 `钻孔编号` | 检查请求体 |
| 柱图无填充 | `地层名称` 未在 `pat_define.json` 配置 | 补图案映射 |
