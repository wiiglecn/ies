## 1. 范围与设计前提

本详细设计覆盖"勘探点平面布置图"新增的**底图导入**、**底图对齐**与**出图比例**三个能力，与现有布孔、图例流程集成。范围限于 `cad/exploration`（ARX 插件 C++ 源码）与 `cad_server/draw_gateway.py`（HTTP 网关）。**本版不包含拟建建筑提取/重画与阴影（影子）绘制**（对应《需求文档》V2.3 §2.3 范围外）。

### 1.1 业务前提（两条并列主流程，V1.6 新增）

本系统按**两条并列的主流程**支持平面图出图，**没有主辅之分**——对没有底图的项目（小型场地、补充勘察、纯勘探点布设）流程一是标准出图路径；对有底图的项目（典型委托方提供总平面图）流程二是标准出图路径。调用方根据“是否持有可用的委托方底图”自行选择，与项目等级、预算无关。

| 维度 | **流程一（无底图）** | **流程二（有底图）** |
| --- | --- | --- |
| 调用方提供 | 仅 `borehole_data`（英文键） | `borehole_data` + `base_map`/`base_map_url` + 可选 `plan_base` |
| 底图导入 | **无此环节**（明确跳过） | `ImportDwgAsBlock` 导入为底图-现状层的整体块参照 |
| 底图对齐 | **无此环节**（明确跳过） | 默认按“同坐标系”导入；配 `registration` 时算平移/旋转/缩放并覆盖 `insert/scale/rotation` |
| 出图比例 | `plot_scale` 配置则缩放“钻孔 + 图例”两层（“底图-现状”层不存在，循环自然跳过）；未配置则不缩放 | `plot_scale` 配置则缩放“底图几何 + 钻孔 + 图例”三层；未配置则不缩放 |
| 布孔 | 按真实坐标 X/Y 插钻孔图块 | 同左 |
| 图例 | 走 `CreateLegend()`，按“勘察点方案+勘察点图例”层求范围定位 | 同左（**注意**：不再被底图绑架，按 §5.4 改造定位） |
| 适用项目 | 小型场地、补充勘察、纯勘探点布设、无甲方底图 | 典型委托方提供总平面图的项目 |

**关于“降级”措辞的封口**：流程一与流程二**都**是正经的出图流程，**不**把流程一说成流程二的“降级/兜底/次选/退化路径”。差异仅在“是否有底图导入+对齐两个环节”，与“是否缩放”无关——`plot_scale` 在两条流程都生效。

### 1.2 目标（含一步式调用的有意差异，V1.6 新增）

**V1.6 新增原则**：参照**理正勘察**两条并列流程的出图思路，补齐“**底图导入 + 底图对齐 + 出图比例**”能力，并明确“**一步式调用（有意差异）**”：

**一步式调用（有意差异，V0.8 / V1.6 拍板）**：本项目**不设独立的“底图初始化”命令**。底图与 `plan_base` 配置（包含两点配准、对齐参数、出图比例）随**“生成平面图”调用一次性提交**，一次 `Execute()` 内完成“底图导入 → 底图对齐 → 出图比例 → 布孔 → 图例 → 出图比例缩放”全部步骤。这与理正两步式（先执行独立的“底图初始化”命令、再执行“生成平面图”命令）是**有意差异**，理由：
1. 与网关一次性无状态接口的语义一致——**每次调用独立落盘、覆盖上次，不保留跨调用的中间状态**；
2. 避免在客户端维护“底图初始化是否已完成”的额外状态机；
3. 与现有 ARX 插件的“一键生成”使用习惯保持一致（`_SLPlanView` 一条命令出图）。
副作用：临时换底图只需再次调用 `/api/draw/plan`（整体重建）；本版不暴露“仅更新底图而不布孔”的细粒度接口。

| # | 前提 / 假设 | 状态 |
| --- | --- | --- |
| 1 | 底图为**委托方提供的现成 DWG**（现状场地/总平面图，含已有建筑、道路、地形、拟建轮廓），插件**只导入不重绘**，以原始内容整体作为一个块参照导入、不分解/不修改 | 已确认（业务反馈 + BR-2） |
| 2 | 底图与钻孔**默认同一坐标系（米）**：不施加任何对齐变换；仅当配置 `registration` 两点配准或显式 `insert/scale/rotation` 时才施加对齐（FR-2.1 / R7） | 已确认（默认行为） |
| 3 | **出图比例**（`plot_scale`，成图比例）作用于**整体成图**（底图几何随之缩放），与用于**坐标对齐**的 `scale` 分离、串联（BR-5），**流程一/流程二都生效**（V1.6 新增） | 已确认（用户拍板）；比例语义/换算待客户确认（见 2.4） |
| 4 | 底图 DWG 与钻孔坐标单位一致（米）；`plan_base.json` 缺失/失败时跳过底图（流程一），完全兼容现有流程 | 已确认 |
| 5 | **流程一**与流程二并列，没有“降级/兜底/次选”之分；流程一只跳过“底图导入+对齐”两步（**V1.6 新增**） | 已确认（V0.8 / V1.6 用户拍板） |
| 6 | **一步式调用**：本项目不设独立的“底图初始化”命令，底图与 `plan_base` 配置随“生成平面图”调用一次性提交；与理正两步式有意差异（**V1.6 新增**） | 已确认（V0.8 / V1.6 用户拍板） |
| 7 | `CUtils::FileExists` 不存在（详设 §5.3 用错了工具）；改用 `PathFileExists`（工程已链接 shlwapi，`CreateColumnView.cpp:111` 在用）；本次同步删除不确定注释（**V1.6 P0-3**） | 已确认（第三轮 H7） |

## 2. 数据定义：`project/plan_base.json`

### 2.1 JSON 结构（定稿）

```json
{
  "base_map": {
    "dwg": "support/底图/05阳光幸福里总平面规划图104(1).dwg",
    "insert_x": 0.0,
    "insert_y": 0.0,
    "scale": 1.0,
    "rotation": 0.0,
    "layer": "底图-现状",
    "dim": false,
    "plot_scale": 500,
    "registration": {
      "source_points": [[2747350.0, 36524890.0], [2747650.0, 36524890.0]],
      "target_points": [[2747450.0, 36524990.0], [2747750.0, 36524990.0]]
    }
  }
}
```

> `registration` 为**可选**；缺省时若亦未显式配置 insert/scale/rotation，则**不施加任何对齐变换**（默认按同一坐标系导入，日志说明）。配准时 `insert_x/y`、`scale`、`rotation` 显式值**被计算值覆盖**（计算见 5.6）。
>
> `plot_scale` 为**可选**；空/未配置 → 不施加出图比例缩放，保持与现状一致（见 5.4）。
>
> **本版删除**：`base_map.proposed_layer`、`shadow.*`、`proposed_buildings`（原拟建提取/阴影/JSON 兜底）。解析时若遇到这些键，忽略、不报错。

### 2.2 字段规则

| 字段 | 类型 | 必填 | 默认 | 规则 |
| --- | --- | --- | --- | --- |
| base_map.dwg | string | 否 | 空 | 相对插件目录（`strFilePath + "/" + dwg`）。空/文件不存在 → 跳过底图导入 |
| base_map.insert_x / insert_y | number | 否 | 0.0 | 底图块插入点（米），**坐标对齐**用 |
| base_map.scale | number | 否 | 1.0 | **坐标对齐**用插入比例（同坐标系同单位时为 1.0）；**与 plot_scale 不同，见 2.4** |
| base_map.rotation | number | 否 | 0.0 | 插入旋转角（弧度） |
| base_map.layer | string | 否 | "底图-现状" | 底图块参照所在图层 |
| base_map.dim | bool | 否 | false | true 时底图块参照整体设色 253（置灰） |
| base_map.plot_scale | number | 否 | 空 | **出图比例分母**（如 500 表示 1:500）；配置后对整体成图施加统一缩放；**空/未配置 → 不施加比例缩放** |
| base_map.registration | object | 否 | 无 | 两点配准（见 2.3）；存在时计算对齐参数并**覆盖** insert/scale/rotation |
| base_map.registration.source_points | array | 配准时必填 | — | 底图（DWG 内部坐标）上已知点，`[x, y]` 数组，1 或 2 个点，单位米 |
| base_map.registration.target_points | array | 配准时必填 | — | 上述点在钻孔坐标系下的对应坐标，数量与 source_points 一致，单位米 |

**解析规则**：所有可选字段缺省时取默认值；数值字段用 `cJSON_IsNumber` 校验，非法则取默认值（配准点非法则回退手动参数）；已删除键（`proposed_layer`/`shadow`/`proposed_buildings`）忽略不报错。

### 2.3 两点配准（registration）模式

| 模式 | source/target 点数 | 计算内容 | 适用场景 |
| --- | --- | --- | --- |
| 两点配准（推荐） | 2 对 | **scale + rotation + insert 三项全算**（相似变换：均匀缩放、整体旋转、平移） | 底图坐标系与钻孔坐标系存在平移/旋转/比例差异（如底图未落当地坐标或单位不同） |
| 单点配准 | 1 对 | 仅算 **insert（平移）**；scale/rotation 取显式配置值（默认 1.0 / 0.0） | 底图与钻孔仅存在平移错位、比例旋转已一致 |

- 配准点应取底图上**稳定、可辨认、间距足够大**的已知坐标点（如已有建筑角点、道路交点、图框角点，且该点在钻孔坐标系下有明确坐标）；
- 两点距离过近（<1e-6 米）或点对数量不匹配 → 打印告警并**回退显式 insert/scale/rotation**（若亦未显式配置，则**不施加变换**，默认同一坐标系导入）；
- 配准结果只在本次导入使用，不修改底图 DWG 文件本身（底图只读）。

### 2.4 出图比例语义（与坐标对齐 scale 的区别，BR-5）

> **本版按用户拍板实现**：出图比例作用于**整体成图**，**底图几何随之缩放**（不是"只作用于注释/打印"）。

| 项 | 对齐 `scale`（`base_map.scale` / registration 计算值） | 出图比例（`base_map.plot_scale`） |
| --- | --- | --- |
| 用途 | **坐标对齐**：消除底图与钻孔的坐标系/单位差异 | **成图输出**：设定成图比例（如 1:500） |
| 同坐标系同单位时 | = 1.0 | 由出图比例决定（≠1） |
| 作用对象 | 仅底图（使其内部坐标落到钻孔坐标系） | **整体成图**（底图几何 + 钻孔落点 + 成果要素） |
| 执行顺序 | 第一步 | 第二步，**串联、顺序固定、互不覆盖** |

**串联关系**：

```
原始底图坐标 p
  ──[第一步：坐标对齐 A]──▶  钻孔坐标 q = A(p) = T + s_align·R(θ_align)·p
  ──[第二步：出图比例 P]──▶  成图坐标 q' = P(q) = O + k_plot·(q − O)
```

- `s_align`：对齐缩放系数（registration 或显式 `scale`）；
- `k_plot`：出图比例因子，由 `plot_scale` 换算（见 5.4）；
- 底图块参照最终 `scale = s_align × k_plot`；**出图比例不覆盖对齐结果**。

> ⚠️ **待客户确认**（呼应《需规》§5.3-3 /《需求文档》§4.3 待确认）：出图比例的准确语义——是否应对**底图整体**施加缩放，还是仅作为**图面比例尺依据**（不改变底图几何）；比例因子的换算与底图绘图单位约定相关（见《需规》§5.4 /《需求文档》§2.4）。本版按"整体缩放"实现。

### 5.3 `ImportBaseMap()` —— 导入委托方 DWG（含对齐）

```cpp
bool CCreatePlanView::ImportBaseMap(const cJSON* cfg)
{
    // 1. 路径（相对插件目录）
    cJSON* dwgItem = CUtils::GetJsonObjectItemUtf8(cfg, _T("dwg"));
    if (dwgItem == NULL || !cJSON_IsString(dwgItem) ||
        dwgItem->valuestring == NULL || dwgItem->valuestring[0] == _T('\0'))
    {
        CUtils::acutPrintf(_T("[CAD INFO] base_map.dwg 未配置，跳过底图导入（V1.6 说明：此分支即流程一跳过底图环节的入口）\n"));
        return false;
    }
    CString dwgPath = strFilePath + _T("/") + CString(dwgItem->valuestring);

    // 2. 文件存在性（V1.6 P0-3：FileExists 不存在 → PathFileExists；工程已链接 shlwapi）
    //    用 #include <shlwapi.h> + PathFileExists（CUtils::FileExists 全库不存在）。
    if (!PathFileExists(dwgPath)) {
        CUtils::acutPrintf(_T("[CAD ERROR] 底图文件不存在：%s\n"), dwgPath.GetString());
        return false;
    }

    // 3. 对齐参数（默认 0,0 / 1.0 / 0）
    BaseMapCfg c;
    c.insertX  = GetJsonNumber(cfg, _T("insert_x"), 0.0);
    c.insertY  = GetJsonNumber(cfg, _T("insert_y"), 0.0);
    c.scale    = GetJsonNumber(cfg, _T("scale"), 1.0);
    c.rotation = GetJsonNumber(cfg, _T("rotation"), 0.0);
    cJSON* layerItem = CUtils::GetJsonObjectItemUtf8(cfg, _T("layer"));
    if (layerItem && cJSON_IsString(layerItem) && layerItem->valuestring)
        c.layer = CString(layerItem->valuestring);
    cJSON* dimItem = CUtils::GetJsonObjectItemUtf8(cfg, _T("dim"));
    // V1.6 P0-7：cJSON_True → cJSON_IsTrue（项目惯例，见 AiApiRequest.cpp:510）
    if (dimItem && cJSON_IsBool(dimItem)) c.dim = cJSON_IsTrue(dimItem);

    // 3.5 对齐决策（FR-2.1 默认行为）
    //     显式对齐键是否存在
    bool hasExplicit =
        CUtils::GetJsonObjectItemUtf8(cfg, _T("insert_x")) != NULL ||
        CUtils::GetJsonObjectItemUtf8(cfg, _T("insert_y")) != NULL ||
        CUtils::GetJsonObjectItemUtf8(cfg, _T("scale"))    != NULL ||
        CUtils::GetJsonObjectItemUtf8(cfg, _T("rotation")) != NULL;

    bool hasReg = ParseRegistration(cfg, c);
    if (hasReg) {
        if (!ComputeRegistration(c)) {
            // 配准失败：回退显式参数；若亦未显式配置 → 不施加变换
            if (!hasExplicit) { c.insertX = c.insertY = 0.0; c.scale = 1.0; c.rotation = 0.0; }
            CUtils::acutPrintf(_T("[CAD INFO] 配准未成功，按%s对齐\n"),
                               hasExplicit ? _T("显式参数") : _T("默认同一坐标系"));
        } else {
            CUtils::acutPrintf(_T("[CAD INFO] 已按两点配准施加对齐变换（先坐标对齐）\n"));
        }
    } else if (!hasExplicit) {
        // 默认行为：未配置任何对齐 → 不施加变换
        CUtils::acutPrintf(_T("[CAD INFO] 未配置对齐，默认按同一坐标系导入（insert=(0,0), scale=1, rotation=0）\n"));
    }

    // 4. 确保图层存在
    if (CUtils::EnsureLayer(c.layer).isNull()) {
        CUtils::acutPrintf(_T("[CAD ERROR] 创建底图图层失败：%s\n"), c.layer.GetString());
        return false;
    }

    // ★ V1.6 BASEPOINT 处理（P1-4）：从 GetExtDb 缓存的源 DWG 读出块 BASEPOINT；
    //    BuildImportMatrix() 中显式扣除基点偏移以免整体错位（详见 §5.3.1）。
    c.hasBasePoint = false;
    {
        AcDbDatabase* pSrc = GetExtDb(dwgPath.GetString());
        if (pSrc != NULL) {
            AcDbBlockTable* pBT = NULL;
            if (pSrc->getBlockTable(pBT, AcDb::kForRead) == Acad::eOk) {
                AcDbBlockTableRecord* pModel = NULL;
                if (pBT->getAt(ACDB_MODEL_SPACE, pModel, AcDb::kForRead) == Acad::eOk) {
                    c.sourceBasePoint = pModel->origin();
                    c.hasBasePoint = true;
                    pModel->close();
                }
                pBT->close();
            }
        }
    }
    if (c.hasBasePoint &&
        fabs(c.sourceBasePoint.x) < 1e-9 && fabs(c.sourceBasePoint.y) < 1e-9) {
        // 等价原点 → 等同未设基点
        c.hasBasePoint = false;
        CUtils::acutPrintf(_T("[CAD INFO] 源 DWG BASEPOINT=原点，按 V1.5 旧矩阵链处理\n"));
    } else if (c.hasBasePoint) {
        CUtils::acutPrintf(_T("[CAD INFO] 源 DWG BASEPOINT=(%.3f, %.3f, %.3f) ≠ 原点，矩阵链中显式扣除基点\n"),
                           c.sourceBasePoint.x, c.sourceBasePoint.y, c.sourceBasePoint.z);
    }

    // 5. 导入为固定名整体块参照（复用基类 6 参重载）
    AcGePoint3d ptInsert(c.insertX, c.insertY, 0.0);
    AcDbObjectId blkDefId = ImportDwgAsBlock(dwgPath.GetString(),
                                             ptInsert,
                                             kBaseMapBlock,
                                             c.scale,
                                             c.rotation,
                                             c.layer.GetString());
    if (blkDefId == AcDbObjectId::kNull) {
        CUtils::acutPrintf(_T("[CAD ERROR] 底图 DWG 导入失败：%s\n"), dwgPath.GetString());
        return false;
    }

    // 5.5 BASEPOINT 校正（V1.6 新增）：ImportDwgAsBlock 的 setPosition 是相对 BASEPOINT 的；
    //     校正公式：把原 insert 用"以 BASEPOINT 为基准修正"的方式设置。
    //     注意：本步骤只对"块参照的 position"做偏移扣减，BLOCK 内的几何坐标不动
    //     （BASEPOINT 不属于块内实体，只表示块表的插入基准；这里调 position 即补偿）。
    //     详见 §5.3.1。
    if (c.hasBasePoint) {
        AcDbBlockReference* pRef = NULL;
        if (this->pModelSpace && acdbOpenObject(pRef, /*refId 略：直接遍历找 */, AcDb::kForWrite) == Acad::eOk) {
            // 在 ApplyPlotScale 阶段（§5.4）会用 BuildImportMatrix 整体 re-transform 一次，
            // 此处不立即改 position，避免与之后缩放叠加混乱。
            pRef->close();
        }
    }

    // 6. 置灰：遍历模型空间，找到块参照 kBaseMapBlock 设色 253
    if (c.dim)
        DimBaseMapReference();

    CUtils::acutPrintf(_T("[CAD INFO] 底图导入成功（整体块参照，不分解）：%s\n"), dwgPath.GetString());
    return true;
}
```

**置灰辅助 `DimBaseMapReference()`**（局部实现，不改基类）：

```cpp
void CCreatePlanView::DimBaseMapReference()
{
    std::vector<AcDbObjectId> refIds;
    AcDbBlockTableRecordIterator* pIt = NULL;
    if (this->pModelSpace->newIterator(pIt) != Acad::eOk || pIt == NULL) return;

    AcDbEntity* pEnt = NULL;
    for (; !pIt->done(); pIt->step()) {
        if (pIt->getEntity(pEnt, AcDb::kForRead) != Acad::eOk) continue;
        if (pEnt->isKindOf(AcDbBlockReference::desc())) {
            AcDbBlockReference* pRef = AcDbBlockReference::cast(pEnt);
            // 比 blockId 比 name 更稳（name 返回临时缓冲区，存在释放歧义）
            AcDbObjectId defId = pRef->blockTableRecord();
            AcDbBlockTable* pBt = NULL;
            if (this->pDb->getBlockTable(pBt, AcDb::kForRead) == Acad::eOk) {
                AcDbObjectId bmId; pBt->getAt(kBaseMapBlock, bmId);
                if (!bmId.isNull() && defId == bmId) refIds.push_back(pRef->objectId());
                pBt->close();
            }
        }
        pEnt->close();
    }
    delete pIt;

    for (size_t i = 0; i < refIds.size(); ++i) {
        AcDbBlockReference* pRef = NULL;
        if (acdbOpenObject(pRef, refIds[i], AcDb::kForWrite) == Acad::eOk) {
            pRef->setColorIndex(kDimColor);
            pRef->close();
        }
    }
}
```

> 说明：置灰仅对块参照本身设色（块内实体若为 ByLayer 则整体变灰；显式颜色实体不变，属可接受的首版行为，详见第 12 章遗留项）。

#### 5.3.1 `BuildImportMatrix()` —— BASEPOINT 校正（V1.6 P1-4 新增）

> **目的**：消除 `ImportDwgAsBlock` 的 `setPosition + setScaleFactors + setRotation` 与源块 BASEPOINT 之间的几何不一致。
>
> **几何**：真实世界变换 = `ptInsert + R(rotation) · scale · (P − BASEPOINT)`；原 V1.5 简化 `ptInsert + R · scale · P` 在 BASEPOINT≠(0,0) 时整张底图偏移 `R·scale·BASEPOINT`。
>
> **方案**：构造矩阵 M：
> ```
> M = T_insert · R(rotation) · S(scale) · Translate(BASEPOINT) · Translate(-BASEPOINT)
> ```
> 即将 BASEPOINT 显式纳入矩阵链，先把点"减去 BASEPOINT"再缩放旋转平移，最后把 BASEPOINT 加回——在外部观感上等价于"扣除基点偏移"。
>
> **应用时机**：本函数在 ApplyPlotScale 阶段对**底图块参照**单独施加一次（不替换原 `setPosition/Scale/Rotation`），确保与缩放链解耦，便于出错排查。

```cpp
// V1.6 P1-4：BASEPOINT 校正矩阵
// 返回值：用于 AcDbBlockReference::transformBy 的"扣基点"矩阵
AcGeMatrix3d CCreatePlanView::BuildImportMatrix(
        const AcGePoint3d& ptInsert,
        double dScale,
        double dRotation,
        const AcGePoint3d& sourceBasePoint /* = AcGePoint3d::kOrigin */)
{
    // M = T(insert) · R(theta) · S(scale) · T(B) · T(-B)
    AcGeMatrix3d mT  = AcGeMatrix3d::translation(ptInsert);
    AcGeMatrix3d mR  = AcGeMatrix3d::rotation(dRotation, AcGeVector3d::kZAxis, AcGePoint3d::kOrigin);
    AcGeMatrix3d mS  = AcGeMatrix3d::scaling(dScale, AcGePoint3d::kOrigin);
    AcGeMatrix3d mTp = AcGeMatrix3d::translation(sourceBasePoint);
    AcGeMatrix3d mTn = AcGeMatrix3d::translation(-sourceBasePoint);

    // 列向量约定（M·P）：从右往左施加变换，先减基点 → 缩放 → 旋转 → 平移 → 加基点对齐
    // 即 M = mT · mR · mS · mTp · mTn
    return mT * mR * mS * mTp * mTn;
}
```

**在 ApplyPlotScale 中调用方式**（V1.6 新增分支）：

```cpp
// 在缩放循环内，对底图块参照额外施加一次 BASEPOINT 校正
if (pEnt->isKindOf(AcDbBlockReference::desc())) {
    AcDbBlockReference* pRef = AcDbBlockReference::cast(pEnt);
    AcDbObjectId defId = pRef->blockTableRecord();
    AcDbBlockTable* pBt = NULL;
    if (this->pDb->getBlockTable(pBt, AcDb::kForRead) == Acad::eOk) {
        AcDbObjectId bmId;
        if (pBt->getAt(kBaseMapBlock, bmId) == Acad::eOk && defId == bmId
            && m_baseCfg.hasBasePoint) {
            // 对底图块参照施加 BASEPOINT 校正矩阵（列向量，M·P）
            AcGeMatrix3d mImport = BuildImportMatrix(
                m_baseCfg.insertBasePoint,    // 视图坐标系的当前插入点
                1.0,                           // 缩放因子=1（缩放由外层 m 控制）
                0.0,                           // 旋转=0（外层缩放矩阵列向量语义不变）
                m_baseCfg.sourceBasePoint);    // 源 DWG 块 BASEPOINT
            // 复合：mTotal = m  ·  mImport  （AcGe 列向量：复合 = 外层后乘内层）
            pRef->transformBy(m * mImport);
            pRef->close();
            pBt->close();
            continue;   // 已处理，不再走外层统一缩放
        }
        pBt->close();
    }
}
// 其它实体走外层 m
p->transformBy(m);
```

> **注**：上述代码在 `ApplyPlotScale()` 缩放循环内对"匹配 `kBaseMapBlock` 的块参照"识别，并对该参照额外施加 BASEPOINT 校正矩阵；其它实体仍走外层统一缩放矩阵 `m`。`hasBasePoint=false`（即 BASEPOINT=原点或读不出）时跳过校正，仍按 V1.5 行为。
>
> 验证：单元测试 T_BP（§10）含 BASEPOINT=(100,200,0) 的源 DWG + 配准对齐后，断言最终"块参照的世界坐标 - 模型空间中已知点"是否对齐（详见 §10）。

### 5.4 `ApplyPlotScale()` —— 出图比例：整体成图统一缩放（V1.5/V1.6 双流程适用）

> **CRITICAL 原则**：底图几何与钻孔落点、以及所有成果要素，必须按**同一比例因子、绕同一基准 O**统一缩放，**绝不允许"只缩底图、不缩钻孔"导致两者错位**。为此，本函数在**本命令全部图元（底图 + 钻孔 + 图例）绘制完成后**，对本命令产生的成果图层施加**同一个**缩放矩阵。
>
> **V1.6 双流程兼容**：流程一（无底图）"底图-现状"层不存在，遍历自然跳过，对"钻孔 + 图例"两层施加缩放；流程二（有底图）三个图层都存在，全部施加；**未配置 `plot_scale` 时不缩放**，与有无底图无关。

```cpp
bool CCreatePlanView::ApplyPlotScale(double plotScaleDenom)
{
    // 0. 未配置 / 非法 → 不缩放（与现状一致，FR-3.1）
    if (plotScaleDenom <= 0.0) {
        CUtils::acutPrintf(_T("[CAD INFO] 出图比例未配置或非法，保持现状（不缩放）\n"));
        return false;
    }

    // 1. 比例因子换算（默认约定 k = 1000 / N；见 2.4 待确认）
    double k = 1000.0 / plotScaleDenom;
    if (!_finite(k) || k <= 0.0) {
        CUtils::acutPrintf(_T("[CAD WARN] 出图比例换算非法（plot_scale=%.3f），回退不缩放\n"), plotScaleDenom);
        return false;
    }
    if (fabs(k - 1.0) < 1e-9) {
        CUtils::acutPrintf(_T("[CAD INFO] 出图比例 1:%.0f，比例因子 k=1.0，无需缩放\n"), plotScaleDenom);
        return true;
    }

    // 2. 统一基准点 O（默认坐标原点）与统一缩放矩阵（绕 O 缩放 k）
    AcGePoint3d O(0.0, 0.0, 0.0);
    AcGeMatrix3d m = AcGeMatrix3d::scaling(k, O);      // p' = O + k·(p − O)

    // 3. 仅对本命令产生的成果图层统一变换，避免影响用户图内其它内容
    const TCHAR* kLayers[3] = { kBaseMapLayer, kPlanHoleLayer, kLegendLayer };
    std::vector<AcDbObjectId> ids;
    AcDbBlockTableRecordIterator* pIt = NULL;
    if (this->pModelSpace->newIterator(pIt) != Acad::eOk || pIt == NULL) return false;
    AcDbEntity* pEnt = NULL;
    for (; !pIt->done(); pIt->step()) {
        if (pIt->getEntity(pEnt, AcDb::kForRead) != Acad::eOk) continue;
        // V1.6 P0-7：图层名比对改 CompareNoCase（与 EraseLayerEntities 一致；AutoCAD 图层不区分大小写）
        for (int i = 0; i < 3; ++i)
            if (CompareNoCase(pEnt->layer(), kLayers[i]) == 0) { ids.push_back(pEnt->objectId()); break; }
        pEnt->close();
    }
    delete pIt;

    // 4. 逐个写打开并施加同一矩阵
    //    V1.6 P1-4：对底图块参照（在 BASEPOINT ≠ (0,0) 时）额外施加 BuildImportMatrix 校正。
    int n = 0;
    for (size_t i = 0; i < ids.size(); ++i) {
        AcDbEntity* p = NULL;
        if (acdbOpenObject(p, ids[i], AcDb::kForWrite) == Acad::eOk) {
            // ★ V1.6 P1-4：识别底图块参照（有 BASEPOINT 校正时复合 m * mImport）
            AcGeMatrix3d mTotal = m;   // 默认仅统一缩放
            if (p->isKindOf(AcDbBlockReference::desc())) {
                AcDbBlockReference* pRef = AcDbBlockReference::cast(p);
                AcDbObjectId defId = pRef->blockTableRecord();
                AcDbBlockTable* pBt = NULL;
                if (this->pDb->getBlockTable(pBt, AcDb::kForRead) == Acad::eOk) {
                    AcDbObjectId bmId;
                    if (pBt->getAt(kBaseMapBlock, bmId) == Acad::eOk && defId == bmId
                        && m_baseCfg.hasBasePoint) {
                        AcGeMatrix3d mImport = BuildImportMatrix(
                            m_baseCfg.sourceInsertPoint, 1.0, 0.0,
                            m_baseCfg.sourceBasePoint);
                        // AcGe 列向量：复合 = 外层（右乘内层）→ mTotal = m * mImport
                        mTotal = m * mImport;
                    }
                    pBt->close();
                }
            }
            p->transformBy(mTotal);
            p->close();
            ++n;
        }
    }
    CUtils::acutPrintf(_T("[CAD INFO] 出图比例 1:%.0f 已应用：k=%.6f，绕基准(%.1f,%.1f) 统一缩放 %d 个成果实体（底图+钻孔+图例）\n"),
                       plotScaleDenom, k, O.x, O.y, n);
    return true;
}
```

**关键性质**：

- **同一矩阵、同一基准**：所有成果图元（含底图块参照、钻孔块参照、图例）都乘以**同一个** `m`，因此底图与钻孔的相对关系不变；
- **不错位证明**：底图内位于钻孔坐标 q 的要素经对齐后落在 q，再经 `m` 得 `P(q)`；钻孔落点为真实钻孔坐标 q，经 `m` 得 `P(q)`。两者落于同一点，天然重合；
- **不动用户其它内容**：仅变换 `底图-现状 / 勘察点方案 / 勘察点图例` 三个图层（均为本命令产生的成果图层）；
- **标注文字内容不缩放**：钻孔编号/高程/深度等文本**内容**来自编录数据（真实值），块参照整体缩放只改变其**大小与位置**，不改变文本所表达的真实坐标；
- **块参照缩放**：`AcDbBlockReference::transformBy` 会同步作用于其 position / scaleFactors，故底图块参照最终 `scale = s_align × k_plot`，与"先对齐后比例"一致。

> 内存/事务：`transformBy` 在两版本均可用；本函数位于同一事务内（第 6 章），失败整体回滚。

### 5.6 两点配准：`ParseRegistration()` + `ComputeRegistration()`

**变换模型（相似变换，4 参数）**：底图 DWG 内部坐标 p（源）→ 钻孔坐标 q（目标）：
`q = T + s · R(θ) · p`，其中 T 为平移（即块插入点 insert），s 为均匀缩放（**对齐** scale，区别于出图比例），θ 为旋转角 rotation。

给定两对点 P1→Q1、P2→Q2（DWG 导入后坐标变换与上式同构，直接对应 `ImportDwgAsBlock` 的 insert/scale/rotation 参数）：

```
dP = P2 - P1          （源向量）
dQ = Q2 - Q1          （目标向量）
s  = |dQ| / |dP|      （均匀缩放，坐标对齐用）
θ  = atan2(dQ.y, dQ.x) - atan2(dP.y, dP.x)   （旋转角，弧度）
T  = Q1 - s · R(θ) · P1                       （平移 = 块插入点）
```

**验证**：`T + s·R(θ)·P1 = Q1`；`T + s·R(θ)·P2 = Q1 + s·R(θ)·dP = Q1 + dQ = Q2` ✓
（`dQ = s·R(θ)·dP` 由 s、θ 定义保证）。单点模式（1 对）时 s、θ 取显式配置值，只算 `T = Q1 - s·R(θ)·P1`。

```cpp
bool CCreatePlanView::ParseRegistration(const cJSON* bm, BaseMapCfg& cfg)
{
    // V1.6 P0-2：registration 可选；缺省 → hasRegistration=false，走手动参数
    cJSON* reg = CUtils::GetJsonObjectItemUtf8(bm, _T("registration"));
    if (reg == NULL || !cJSON_IsObject(reg)) return false;

    cJSON* src = CUtils::GetJsonObjectItemUtf8(reg, _T("source_points"));
    cJSON* tgt = CUtils::GetJsonObjectItemUtf8(reg, _T("target_points"));
    if (src == NULL || tgt == NULL || !cJSON_IsArray(src) || !cJSON_IsArray(tgt)) {
        CUtils::acutPrintf(_T("[CAD WARN] registration 结构无效（需要 source_points/target_points 数组），回退手动对齐参数\n"));
        return false;
    }

    int nSrc = cJSON_GetArraySize(src), nTgt = cJSON_GetArraySize(tgt);
    if (nSrc != nTgt || nSrc < 1 || nSrc > 2) {
        CUtils::acutPrintf(_T("[CAD WARN] registration 点数不匹配或超范围（源 %d / 目标 %d，需 1~2 对），回退手动对齐参数\n"), nSrc, nTgt);
        return false;
    }

    // ★ V1.6 P0-2 修复：原 V1.5 按 {"x":..,"y":..} 对象解析（错误），与 §2.1 JSON 定稿的
    //   [x, y] 数组（L60-61）矛盾，导致两点配准静默回退。改为按数组解析：
    //   每个元素是 [x, y]，下标 0/1 两个 cJSON_IsNumber 成员；任一不满足 → 该点无效 → 整组回退。
    int i = 0;
    cJSON* ps = NULL;
    cJSON_ArrayForEach(ps, src) {
        if (!cJSON_IsArray(ps) || cJSON_GetArraySize(ps) != 2) {
            CUtils::acutPrintf(_T("[CAD WARN] registration 源点 %d 不是 [x,y] 数组，回退手动对齐参数\n"), i + 1);
            return false;
        }
        cJSON* sx = cJSON_GetArrayItem(ps, 0);
        cJSON* sy = cJSON_GetArrayItem(ps, 1);
        if (sx == NULL || sy == NULL || !cJSON_IsNumber(sx) || !cJSON_IsNumber(sy)) {
            CUtils::acutPrintf(_T("[CAD WARN] registration 源点 %d 元素非数字，回退手动对齐参数\n"), i + 1);
            return false;
        }
        cfg.srcPts[i] = AcGePoint2d(sx->valuedouble, sy->valuedouble);
        ++i;
    }
    i = 0;
    cJSON* pt = NULL;
    cJSON_ArrayForEach(pt, tgt) {
        if (!cJSON_IsArray(pt) || cJSON_GetArraySize(pt) != 2) {
            CUtils::acutPrintf(_T("[CAD WARN] registration 目标点 %d 不是 [x,y] 数组，回退手动对齐参数\n"), i + 1);
            return false;
        }
        cJSON* tx = cJSON_GetArrayItem(pt, 0);
        cJSON* ty = cJSON_GetArrayItem(pt, 1);
        if (tx == NULL || ty == NULL || !cJSON_IsNumber(tx) || !cJSON_IsNumber(ty)) {
            CUtils::acutPrintf(_T("[CAD WARN] registration 目标点 %d 元素非数字，回退手动对齐参数\n"), i + 1);
            return false;
        }
        cfg.tgtPts[i] = AcGePoint2d(tx->valuedouble, ty->valuedouble);
        ++i;
    }

    cfg.regPtCount    = nSrc;
    cfg.hasRegistration = true;
    return true;
}

bool CCreatePlanView::ComputeRegistration(BaseMapCfg& cfg)
{
    if (!cfg.hasRegistration || cfg.regPtCount < 1) return false;

    double s = cfg.scale, theta = cfg.rotation;   // 单点模式沿用显式值
    AcGeVector2d dP, dQ;
    if (cfg.regPtCount == 2) {
        dP = cfg.srcPts[1] - cfg.srcPts[0];
        dQ = cfg.tgtPts[1] - cfg.tgtPts[0];
        double lenP = dP.length();
        if (lenP < 1e-6) {
            CUtils::acutPrintf(_T("[CAD WARN] registration 两点距离过小（%.6f），无法计算比例/旋转，回退手动对齐参数\n"), lenP);
            cfg.hasRegistration = false;
            return false;
        }
        s     = dQ.length() / lenP;
        theta = atan2(dQ.y, dQ.x) - atan2(dP.y, dP.x);
    }

    double cs = cos(theta), sn = sin(theta);
    double tX = cfg.tgtPts[0].x - s * ( cs * cfg.srcPts[0].x - sn * cfg.srcPts[0].y);
    double tY = cfg.tgtPts[0].y - s * ( sn * cfg.srcPts[0].x + cs * cfg.srcPts[0].y);

    if (!_finite(s) || !_finite(theta) || !_finite(tX) || !_finite(tY) || s <= 0.0) {
        CUtils::acutPrintf(_T("[CAD WARN] registration 计算结果非法，回退手动对齐参数\n"));
        cfg.hasRegistration = false;
        return false;
    }

    cfg.scale    = s;
    cfg.rotation = theta;
    cfg.insertX  = tX;
    cfg.insertY  = tY;
    CUtils::acutPrintf(_T("[CAD INFO] 两点配准成功：scale=%.6f rotation=%.6f rad insert=(%.3f, %.3f)\n"),
                       s, theta, tX, tY);
    return true;
}
```

> 说明：
> 1. 使用 `AcGeVector2d`（`atan2`/`length()`/`-` 均为其原生运算），也可用 `double` 手算替代，不依赖额外库；
> 2. `_finite` 为 MSVC 数学宏（`<float.h>`），2005/2007 均可用；
> 3. 配准只改**导入参数**，底图 DWG 文件与块定义内容不被修改（符合"底图只读"原则）；
> 4. 两点近似重合（`lenP` 过小）与非法数值均回退手动参数（或默认不施加变换），绝不带病插入。

## 6. `Execute()` 集成（V1.5 / V1.6 双流程共用）

`features/CreatePlanView.cpp` 的 `Execute()` 在 `actionBefore()` 之后、布孔之前插入 `DrawBaseMap()`，并在布孔与图例完成后统一施加出图比例。**V1.6 双流程共用同一 `Execute()`**：

```cpp
    int ret = this->actionBefore();
    if (ret != 0 ) { aboutTrans(); return; }

    // ★ V1.6：底图导入 + 对齐（流程二路径；流程一无底图时 DrawBaseMap() 内部打印告警并跳过）
    //        失败不阻断，内部已打印告警；详见 §5.1
    DrawBaseMap();

    const TCHAR* layerName = _T("勘察点方案");
    ... // 原有布孔逻辑不变（按真实坐标插入钻孔，写编号/高程/深度）

    ... // 原有图例逻辑 CreateLegend() 不变（V1.6 改造按"勘察点方案+勘察点图例"层求范围，详 §5.4）

    // ★ V1.6：出图比例——对整体成图统一缩放。
    //         流程二缩放"底图几何 + 钻孔 + 图例"三层；
    //         流程一缩放"钻孔 + 图例"两层（"底图-现状"层不存在自然跳过）。
    //         m_plotScale<=0（未配置）时内部直接返回，不缩放。
    ApplyPlotScale(m_plotScale);

    ... // commitTrans() / actionEnd() / regen()
```

**一步式调用（V1.6 明示）**：本系统**不设独立的"底图初始化"命令**。`DrawBaseMap()` + `CreateLegend()` + `ApplyPlotScale()` 三步均内联在本 `Execute()` 内一次性完成，不在 ARX 层暴露"分步出图"的细粒度接口。这与理正两步式（先独立的"底图初始化"命令，再"生成平面图"命令）是**有意差异**，理由同 §1.2（与网关一次性无状态接口一致、不保留跨命令中间状态）。

**事务**：`DrawBaseMap()` 与 `ApplyPlotScale()` 均位于 `startTrans()` 之后、`commitTrans()` 之前，与布孔/图例同一事务，"一键生成"整体可回滚。

**顺序要点**：出图比例缩放必须放在**布孔与图例都完成之后**（对本命令全部成果图层一次性施加同一矩阵），从而保证"底图/钻孔/图例"三者不错位；绝不能在底图或钻孔阶段分别、以不同参数缩放。

**成员变量**：新增 `double m_plotScale = 0.0;` 与 `BaseMapCfg m_baseCfg;`（在 `CreatePlanView.h` 类内声明），由 `DrawBaseMap()` 写入、`ApplyPlotScale()` 读取（BASEPOINT + insert 参数）。

```python
def _is_loopback(host):
    """V1.6 P0-8：解析 hostname，回环地址一律拒绝。"""
    try:
        infos = socket.getaddrinfo(host, None)
        for fam, *_rest, sockaddr in infos:
            ip = sockaddr[0]
            try:
                ip_obj = ipaddress.ip_address(ip)
            except ValueError:
                continue
            if ip_obj.is_loopback:
                return True
    except Exception:
        return False
    return False

def _ssrf_check(host):
    """V1.6 P0-8：仅允许 http/https + 禁回环；私网/公网默认全放行；
       若 --ssrf-whitelist-cidr 非空则只放行白名单内。"""
    if not host:
        return False
    if SSRF_DENY_LOOPBACK and _is_loopback(host):
        return False
    if SSRF_WHITELIST_CIDR:
        try:
            infos = socket.getaddrinfo(host, None)
            ips = [sockaddr[0] for fam, *_, sockaddr in infos]
        except Exception:
            return False
        for ip in ips:
            try:
                if any(ipaddress.ip_address(ip) in ipaddress.ip_network(c, strict=False)
                       for c in SSRF_WHITELIST_CIDR):
                    return True
            except ValueError:
                continue
        return False
    return SSRF_DEFAULT_ALLOW_ALL

def _http_get_with_redirects(url, timeout):
    """V1.6 P0-8：手动重定向跟随（最多 3 次），每跳独立 SSRF 校验 + 累计字节限流。"""
    LIMIT_REDIRECTS = 3
    for _ in range(LIMIT_REDIRECTS + 1):
        u = urllib.parse.urlparse(url)
        if u.scheme not in ("http", "https"):
            raise ValueError("only http(s) allowed")
        if not _ssrf_check(u.hostname):
            raise ValueError(f"ssrf denied host: {u.hostname}")
        req = urllib.request.Request(url)
        class _NoRedirect(urllib.request.HTTPRedirectHandler):
            def redirect_request(self, *a, **kw): return None
        opener = urllib.request.build_opener(_NoRedirect())
        with opener.open(req, timeout=timeout) as r:
            if r.status in (301, 302, 303, 307, 308):
                url = r.headers.get("Location", "")
                if not url:
                    raise ValueError("redirect missing Location")
                continue
            data = bytearray()
            while len(data) <= DWG_MAX_BYTES:
                chunk = r.read(64 * 1024)
                if not chunk:
                    return bytes(data)
                data.extend(chunk)
            raise ValueError("base_map too large (>50MB)")
    raise ValueError("too many redirects (>3)")

def _save_base_map():
    """返回 (rel_path | None, warnings) 二元组：
       - rel_path 底图相对路径（相对 ARX_DIR，正斜杠）；未提供/不可用 → None
       - warnings  告警列表（字符串数组），用于 §9.3 写入 HTTP 响应的 `warnings[]` 字段
                  **任何底图不可用都会进 warnings**（告警必达，禁止仅日志/静默）
       **错误分类**（按用户拍板的需求层行为口径 NFR-6 / R22）：
       a) **调用方式错误**（400，warnings 不写）：同传 base_map + base_map_url、扩展名非 .dwg；
       b) **底图不可用**（200，warnings 必达）：
          - 文件不存在（f.filename 给了但本机上 path 找不到）
          - 文件上传 >50MB（包含到 body 里但超过 50MB 阈值）
          - URL 下载失败/超时/重定向过多/SSRF 拒回环/DWG 版本过高
       c) **未提供**（None + 无 warnings，走流程一）
       V1.6 P1-6：移出 _lock；同名即覆盖；V1.6 P0-8：SSRF 校验。"""
    f = request.files.get("base_map")
    url = (request.form.get("base_map_url") or "").strip()
    if f and f.filename and url:
        # (a) 调用方式错误 → 400（不是底图不可用，warnings 不写）
        raise ValueError("base_map 与 base_map_url 互斥，二选一")
    if f and f.filename:
        safe = os.path.basename(f.filename)
        # (a) 扩展名错误 → 400
        if not safe.lower().endswith(".dwg"):
            raise ValueError("only .dwg allowed")
        try:
            data = f.read(DWG_MAX_BYTES + 1)
        except Exception as e:
            # (b) 上传 IO 异常 → 200 + warning
            return None, [f"底图未被采用：文件上传读取失败（{type(e).__name__}：{e}）"]
        if len(data) > DWG_MAX_BYTES:
            # (b) 超过 50MB → 200 + warning
            return None, [f"底图未被采用：base_map 超过 50MB 上限（实际 {len(data)} 字节）"]
        if len(data) == 0:
            # (b) 空文件 → 200 + warning
            return None, ["底图未被采用：base_map 为空文件"]
        os.makedirs(BASE_MAP_DIR, exist_ok=True)
        dst = os.path.join(BASE_MAP_DIR, safe)            # 同名 → 直接覆盖
        try:
            with open(dst, "wb") as w:
                w.write(data)
        except OSError as e:
            # (b) 落盘失败 → 200 + warning（不 5xx）
            return None, [f"底图未被采用：落盘失败（{e}）"]
        return f"support/底图/{safe}", []
    if url:
        # 扩展名校验（先做，不发起请求）→ 400
        name = os.path.basename(urllib.parse.urlparse(url).path) or "base_map.dwg"
        if not name.lower().endswith(".dwg"):
            raise ValueError("base_map_url must point to .dwg")
        try:
            data = _http_get_with_redirects(url, URL_TIMEOUT)
        except ValueError as e:
            # (b) SSRF 拒回环 / 协议非 http(s) / 重定向过多 / 大小超限
            #     ValueError 即"底图不可用"，但 SSRF 命中内网是攻击行为，**不写 warnings**（不泄露拒因），
            #     仅记录网关侧 access log；上层仍走 200 + 仅 "底图未被采用：URL 校验未通过"
            msg = str(e)
            if "ssrf denied" in msg or "only http(s)" in msg:
                # 攻击行为：不写明告警文案（避免给攻击者反馈），统一 "URL 校验未通过"
                return None, ["底图未被采用：base_map_url 校验未通过（详见网关日志）"]
            # 其它 ValueError（大小/重定向）→ 200 + warning
            return None, [f"底图未被采用：{msg}"]
        except Exception as e:
            # (b) URL 下载失败/超时/DNS 失败/连接错误 → 200 + warning
            return None, [f"底图未被采用：URL 下载失败（{type(e).__name__}：{e}）"]
        if not data:
            return None, ["底图未被采用：base_map_url 响应为空"]
        os.makedirs(BASE_MAP_DIR, exist_ok=True)
        dst = os.path.join(BASE_MAP_DIR, name)
        try:
            with open(dst, "wb") as w:
                w.write(data)
        except OSError as e:
            return None, [f"底图未被采用：URL 内容落盘失败（{e}）"]
        return f"support/底图/{name}", []
    # (c) 未提供底图 → 走流程一，warnings 空
    return None, []
```

> 说明：只取文件名（`os.path.basename`）防路径穿越；URL 仅 http/https、SSRF 校验、限 `.dwg` 与大小、限重定向 3 次；**调用方式错误**（同传 / 扩展名）抛 `ValueError` → 外层 400；**底图不可用**（文件不存在/超限/下载失败/超时/SSRF 拒回环/落盘失败）→ 200 + `warnings[]` 显式告警（**告警必达**，与 NFR-6 / 需规 §3.5 R22 一致）。SSRF 命中内网/回环属**攻击行为**，不写明告警文案以避免给攻击者反馈，仅统一"URL 校验未通过"。**`_save_base_map` 在 `_lock` 外调用**；同名即覆盖。**下载全部发生在网关端**，插件端只读本地落盘文件、不访问网络（NFR-8）。

### 9.3 三个生成接口（**V1.6 三接口共用 `_resolve_form_json()`**）

> ⚠️ **实现状态（P2-2）**：以下三接口为**目标需求、本版待实现**；现网关与代码仍为单接口 `/api/draw`（`draw_gateway.py:184`）。改造时复用现有 `_write_json` / `_translate_*` / `_call_cad` / `_lock`。

**关键修复（V1.6 P0-1）**：`request.get_json(force=True, silent=True)` 在 multipart 调用下因 `content-type ≠ application/json` 恒返回 None（即使 `silent=True`）。原 V1.5 代码仅 `borehole_data` 有 `request.form` 兜底，且未对 form 串 `json.loads`；`plan_base` / `section_params` 完全读不到。**V1.6 修复**：定义共用解析函数 `_resolve_form_json()`（JSON body 优先 → form 字段 `json.loads` 兜底 → 非法 JSON 抛 ValueError），三接口统一调用；`auto_zoom` 单独走 `request.form.get` + JSON body 兜底（无需 `json.loads`，是 bool）。

```python
def _resolve_form_json(field_name, required=False):
    """V1.6 P0-1 共用参数解析：
       1) 优先从 JSON body 取（application/json 提交时）
       2) 否则从 form 字段取字符串，json.loads 解析（multipart 提交时）
       3) 非法 JSON 抛 ValueError → 外层捕获回 400；required=True 且全无值抛 ValueError。
       返回值可能是 dict/list。"""
    # 1) JSON body
    try:
        body = request.get_json(silent=True) or {}
    except Exception:
        body = {}
    if field_name in body and body[field_name] is not None:
        v = body[field_name]
        if isinstance(v, (dict, list)):
            return v
        if isinstance(v, str):
            try:
                return json.loads(v)
            except Exception:
                raise ValueError(f"{field_name} invalid JSON in body")
        return v
    # 2) form 字段（multipart）
    raw = request.form.get(field_name)
    if raw:
        try:
            return json.loads(raw)
        except Exception:
            raise ValueError(f"{field_name} invalid JSON in form")
    # 3) required 检查
    if required:
        raise ValueError(f"missing required field: {field_name}")
    return None

def _remove_if_exists(path):
    if os.path.exists(path):
        os.remove(path)
```

> **V1.6 同日小修订·告警必达**：`draw_plan` 响应体**永远包含** `warnings[]` 与 `degraded_to` 字段（即使为空 / null）；`warnings` 含"底图未被采用：xxx" 时表示本次底图未生效但流程按流程一继续出图；CAD 端在 `_call_cad` 成功返回后**必须**解析 `warnings[]` 并**显式**通过 `acedAlert` / 命令行 `acutPrintf` 告知用户，**禁止仅记日志**。返回结构示例见函数 docstring。

| 项 | 设计 |

| **plan 视图超时**（V1.6） | `_call_cad(VIEW_ROUTES["plan"], timeout=300)`；超时返回 504；其它视图沿用 120s |
| **base_map 与 base_map_url 同传**（V1.6） | 一律报 HTTP 400；语义明确 |
| 文件安全 | 底图 `os.path.basename` 取文件名防路径穿越；限 `.dwg` 扩展名；体积上限 50MB |

| 只读原则 | 底图 DWG 与编录数据只读，生成过程不修改源文件 |
| 响应 | 统一 `{status, results, errors}`；生成接口返回对应视图调用结果 |
