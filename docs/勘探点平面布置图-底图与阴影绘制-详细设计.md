## 1. 范围与设计前提

本详细设计覆盖"勘探点平面布置图"新增的**底图导入**与**拟建建筑阴影**两个能力，与现有布孔、图例流程集成。范围限于 `cad/exploration`（ARX 插件 C++ 源码）与 `cad_server/draw_gateway.py`（HTTP 网关）。

**设计前提（沿用概要设计 V0.2，含未确认假设）：**

| # | 前提 / 假设 | 状态 |
| --- | --- | --- |
| 1 | 底图为**委托方提供的现成 DWG**（现状场地/总平面图，含已有建筑、道路、地形），插件只导入不重绘 | 已确认（业务反馈） |
| 2 | 底图与钻孔坐标**同一坐标系（米）**，默认插入 (0,0)、比例 1、旋转 0 即对齐；错位时优先用 **`registration` 两点配准**自动计算对齐参数（首版能力），无配准数据时回退手动 insert/scale/rotation | 假设（按行业惯例，待实测确认） |
| 3 | **拟建建筑轮廓由底图 DWG 提供**：总平面图惯例画在专门图层（如"拟建建筑"），插件按 `base_map.proposed_layer` 提取并绘制粗线+阴影；`proposed_buildings`（JSON 轮廓）为可选兜底 | 已确认（业务反馈：底图含拟建轮廓） |
| 4 | 底图 DWG 与钻孔坐标单位一致（米）；`plan_base.json` 缺失/失败时跳过底图，完全兼容现有流程 | 已确认 |

## 2. 数据定义：`project/plan_base.json`

### 2.1 JSON 结构（定稿）

```json

    "scale": 1.0,
    "rotation": 0.0,

    "proposed_layer": "0-规划建筑",
    "registration": {
      "source_points": [[2747350.0, 36524890.0], [2747650.0, 36524890.0]],
      "target_points": [[2747450.0, 36524990.0], [2747750.0, 36524990.0]]
    }
  },
  "shadow": { "dx": 1.5, "dy": -1.5, "enabled": true },
  "proposed_buildings": [
    {
      "name": "1#拟建楼",
      "floors": 18,
      "outline": [
        { "x": 2747370.0, "y": 36524930.0 },
        { "x": 2747395.0, "y": 36524930.0 },
        { "x": 2747395.0, "y": 36524955.0 },
        { "x": 2747370.0, "y": 36524955.0 }
      ]
    }
  ]

```

> `registration` 为**可选**；缺省时行为与 V1.0 完全一致（手动 insert/scale/rotation）。配准时 `insert_x/y`、`scale`、`rotation` 显式值**被计算值覆盖**（计算见 5.7）。
>
> **拟建轮廓二选一（V1.2）**：配置了 `base_map.proposed_layer` 且提取到闭合轮廓 → 从底图提取（推荐，见 5.8）；未配置或提取失败 → 回退 `proposed_buildings`（JSON 兜底）。两者都不存在 → 跳过拟建绘制。

### 2.2 字段规则

| 字段 | 类型 | 必填 | 默认 | 规则 |
| --- | --- | --- | --- | --- |
| base_map.dwg | string | 否 | 空 | 相对插件目录（`strFilePath + "/" + dwg`）。空/文件不存在 → 跳过底图导入 |
| base_map.insert_x / insert_y | number | 否 | 0.0 | 底图块插入点（米） |
| base_map.scale | number | 否 | 1.0 | 插入比例 |
| base_map.rotation | number | 否 | 0.0 | 插入旋转角（弧度） |
| base_map.layer | string | 否 | "底图-现状" | 底图块参照所在图层 |
| base_map.dim | bool | 否 | false | true 时底图块参照整体设色 253（置灰） |
| base_map.registration | object | 否 | 无 | 两点配准（见 2.3）；存在时计算对齐参数并**覆盖** insert/scale/rotation |
| base_map.registration.source_points | array | 配准时必填 | — | 底图（DWG 内部坐标）上已知点，`[x, y]` 数组，1 或 2 个点，单位米 |
| base_map.registration.target_points | array | 配准时必填 | — | 上述点在钻孔坐标系下的对应坐标，数量与 source_points 一致，单位米 |
| base_map.proposed_layer | string | 否 | 空 | 拟建建筑轮廓所在图层名（底图 DWG 内的图层）；配置且提取到闭合轮廓时**优先于** proposed_buildings（V1.2）。**真实项目取值＝`0-规划建筑`**（客户底图截图确认 2026-10-13，底图 `05阳光幸福里总平面规划图104(1).dwg`） |
| shadow.dx / shadow.dy | number | 否 | 1.5 / -1.5 | 影子平移偏移（米） |
| shadow.enabled | bool | 否 | true | false 时只画拟建轮廓不画影子 |
| proposed_buildings[].name | string | 否 | 空 | 备注用（首版不写图内文本） |
| proposed_buildings[].floors | number | 否 | 0 | 备注用（首版不写图内文本） |
| proposed_buildings[].outline | array | 兜底时是 | — | `{x,y}` 数组，≥3 点，闭合多边形，单位米；**仅当未配置 proposed_layer 或底图提取失败时使用**（V1.2） |

**解析规则**：所有可选字段缺省时取默认值；`outline` 解析失败或点数 <3 时跳过该建筑并打印告警；数值字段用 `cJSON_IsNumber` 校验，非数字跳过该建筑。

### 2.3 两点配准（registration）模式

| 模式 | source/target 点数 | 计算内容 | 适用场景 |
| --- | --- | --- | --- |
| 两点配准（推荐） | 2 对 | **scale + rotation + insert 三项全算**（相似变换：均匀缩放、整体旋转、平移） | 底图坐标系与钻孔坐标系存在平移/旋转/比例差异（最常见，如底图未落当地坐标或单位不同） |
| 单点配准 | 1 对 | 仅算 **insert（平移）**；scale/rotation 取显式配置值（默认 1.0 / 0.0） | 底图与钻孔仅存在平移错位、比例旋转已一致 |

- 配准点应取底图上**稳定、可辨认、间距足够大**的已知坐标点（如已有建筑角点、道路交点、图框角点，且该点在钻孔坐标系下有明确坐标）；
- 两点距离过近（<1e-6 米）或点对数量不匹配 → 打印告警并**回退显式 insert/scale/rotation**；
- 配准结果只在本次导入使用，不修改底图 DWG 文件本身（底图只读）。

## 5. 函数详细设计

### 5.1 `DrawBaseMap()` —— 主入口

```cpp
bool CCreatePlanView::DrawBaseMap()
{
    // 1. 清旧底图（重复生成可重建）
    EraseBaseMapLayers();

    // 2. 加载 plan_base.json（静默模式，失败不阻断）
    CString url = strFilePath + _T("project/plan_base.json");
    cJSON* cfg = CUtils::LoadJsonFile(url.GetString());
    if (cfg == NULL) {
        CUtils::acutPrintf(_T("[CAD INFO] 未找到底图配置 project/plan_base.json，跳过底图\n"));
        return false;
    }

    // 3. 解析 shadow（可选，先于底图解析，供提取/兜底共用）
    ShadowParam sp;
    cJSON* sh = CUtils::GetJsonObjectItemUtf8(cfg, _T("shadow"));
    if (sh != NULL) {
        sp.dx      = GetJsonNumber(sh, _T("dx"), 1.5);
        sp.dy      = GetJsonNumber(sh, _T("dy"), -1.5);
        cJSON* en  = CUtils::GetJsonObjectItemUtf8(sh, _T("enabled"));
        if (en && cJSON_IsBool(en)) sp.enabled = (en->type == cJSON_True);
    }

    // 4. 解析 base_map（可选）
    bool useLayerExtract = false;
    cJSON* bm = CUtils::GetJsonObjectItemUtf8(cfg, _T("base_map"));
    if (bm != NULL) {
        // V1.2：proposed_layer 配置 → 拟建轮廓走"底图提取"（导入内部完成）
        cJSON* pl = CUtils::GetJsonObjectItemUtf8(bm, _T("proposed_layer"));
        useLayerExtract = (pl != NULL && cJSON_IsString(pl) &&
                           pl->valuestring != NULL && pl->valuestring[0] != _T('\0'));
        ImportBaseMap(bm, sp);
    }

    // 5. 拟建建筑：底图提取优先，JSON 兜底（V1.2）
    if (!useLayerExtract) {
        cJSON* pb = CUtils::GetJsonObjectItemUtf8(cfg, _T("proposed_buildings"));
        if (pb != NULL && cJSON_IsArray(pb))
            DrawProposedBuildings(pb, sp);
    }

    cJSON_free(cfg);
    return true;
}
```

**职责要点**：任何子步骤失败都只打印告警、不抛异常、不阻断布孔（调用方 `Execute` 后续继续）。拟建轮廓二选一：`proposed_layer` 已配置 → 由 `ImportBaseMap` 内提取（5.8）；否则 JSON 兜底（5.4）。

### 5.2 `EraseBaseMapLayers()` —— 清旧重建

```cpp
void CCreatePlanView::EraseBaseMapLayers()
{
    CUtils::EraseLayerEntities(this->pModelSpace, kBaseMapLayer);   // 底图现状层
    CUtils::EraseLayerEntities(this->pModelSpace, kProposedLayer);  // 拟建层
    CUtils::EraseLayerEntities(this->pModelSpace, kShadowLayer);    // 阴影层
    CUtils::EraseBlock(this->pModelSpace, kBaseMapBlock);           // 旧底图块（含参照+定义）
}
```

> 图层不存在时 `EraseLayerEntities` 应幂等（内部按层名查找，找不到返回 0）；`EraseBlock` 块不存在返回成功（现有语义）。

### 5.3 `ImportBaseMap()` —— 导入委托方 DWG + 提取拟建轮廓

```cpp
bool CCreatePlanView::ImportBaseMap(const cJSON* cfg, const ShadowParam& sp)
{
    // 1. 路径（相对插件目录）
    cJSON* dwgItem = CUtils::GetJsonObjectItemUtf8(cfg, _T("dwg"));
    if (dwgItem == NULL || !cJSON_IsString(dwgItem) ||
        dwgItem->valuestring == NULL || dwgItem->valuestring[0] == _T('\0'))
    {
        CUtils::acutPrintf(_T("[CAD INFO] base_map.dwg 未配置，跳过底图导入\n"));
        return false;
    }
    CString dwgPath = strFilePath + _T("/") + CString(dwgItem->valuestring);

    // 2. 文件存在性
    if (CUtils::FileExists(dwgPath) == false) {            // 若工具不存在则用 GetFileAttributes
        CUtils::acutPrintf(_T("[CAD ERROR] 底图文件不存在：%s\n"), dwgPath.GetString());
        return false;
    }

    // 3. 对齐参数（默认 0,0 / 1.0 / 0）
    BaseMapCfg cfg2;
    cfg2.insertX  = GetJsonNumber(cfg, _T("insert_x"), 0.0);
    cfg2.insertY  = GetJsonNumber(cfg, _T("insert_y"), 0.0);
    cfg2.scale    = GetJsonNumber(cfg, _T("scale"), 1.0);
    cfg2.rotation = GetJsonNumber(cfg, _T("rotation"), 0.0);
    cJSON* layerItem = CUtils::GetJsonObjectItemUtf8(cfg, _T("layer"));
    if (layerItem && cJSON_IsString(layerItem) && layerItem->valuestring)
        cfg2.layer = CString(layerItem->valuestring);
    cJSON* dimItem = CUtils::GetJsonObjectItemUtf8(cfg, _T("dim"));
    if (dimItem && cJSON_IsBool(dimItem)) cfg2.dim = (dimItem->type == cJSON_True);

    // V1.2：拟建轮廓所在图层（空 = 不提取，走 JSON 兜底）
    cJSON* plItem = CUtils::GetJsonObjectItemUtf8(cfg, _T("proposed_layer"));
    if (plItem && cJSON_IsString(plItem) && plItem->valuestring)
        cfg2.proposedLayer = CString(plItem->valuestring);

    // 3.5 ★ V1.1 两点配准：若配置 registration，计算四参数并覆盖 insert/scale/rotation
    //     （成功则 cfg2.insertX/Y、cfg2.scale、cfg2.rotation 为配准结果；失败回退显式参数）
    ParseRegistration(cfg, cfg2);
    ComputeRegistration(cfg2);

    // 4. 确保图层存在
    if (CUtils::EnsureLayer(cfg2.layer).isNull()) {
        CUtils::acutPrintf(_T("[CAD ERROR] 创建底图图层失败：%s\n"), cfg2.layer.GetString());
        return false;
    }

    // 5. 导入为固定名块（复用基类重载：支持插入点/比例/旋转/图层）
    AcGePoint3d ptInsert(cfg2.insertX, cfg2.insertY, 0.0);
    AcDbObjectId blkDefId = ImportDwgAsBlock(dwgPath.GetString(),
                                             ptInsert,
                                             kBaseMapBlock,
                                             cfg2.scale,
                                             cfg2.rotation,
                                             cfg2.layer.GetString());
    if (blkDefId == AcDbObjectId::kNull) {
        CUtils::acutPrintf(_T("[CAD ERROR] 底图 DWG 导入失败：%s\n"), dwgPath.GetString());
        return false;
    }

    // 6. 置灰：遍历模型空间，找到块参照 kBaseMapBlock 设色 253
    if (cfg2.dim)
        DimBaseMapReference();

    // 7. ★ V1.2：拟建轮廓从底图提取（配置了 proposed_layer 时；失败仅告警，不阻断）
    if (!cfg2.proposedLayer.IsEmpty())
        ExtractProposedFromBaseMap(cfg2, sp);

    CUtils::acutPrintf(_T("[CAD INFO] 底图导入成功：%s\n"), dwgPath.GetString());
    return true;
}
```

**置灰辅助 `DimBaseMapReference()`**（局部实现，不改基类）：

```cpp
void CCreatePlanView::DimBaseMapReference()
{
    // 先收集块参照 ObjectId，再统一以写方式设色（避免迭代中写打开）
    std::vector<AcDbObjectId> refIds;
    AcDbBlockTableRecord* pMS = this->pModelSpace;
    AcDbBlockTableRecordIterator* pIt = NULL;
    if (pMS->newIterator(pIt) != Acad::eOk || pIt == NULL) return;

    AcDbEntity* pEnt = NULL;
    for (; !pIt->done(); pIt->step()) {
        if (pIt->getEntity(pEnt, AcDb::kForRead) != Acad::eOk) continue;
        if (pEnt->isKindOf(AcDbBlockReference::desc())) {
            AcDbBlockReference* pRef = AcDbBlockReference::cast(pEnt);
            if (pRef->name() == kBaseMapBlock)
                refIds.push_back(pRef->objectId());
        }
        pEnt->close();
    }
    delete pIt;

    for (size_t i = 0; i < refIds.size(); ++i) {
        AcDbBlockReference* pRef = NULL;
        if (acdbOpenObject(pRef, refIds[i], AcDb::kForWrite) == Acad::eOk) {
            pRef->setColorIndex(kDimColor);
            pRef->close();
        }
    }
}
```

> 说明：置灰仅对块参照本身设色（块内实体若为 ByLayer 则整体变灰；显式颜色实体不变，属可接受的首版行为，详见 8 章遗留项）。

### 5.4 `DrawProposedBuildings()` —— 拟建建筑轮廓 + 阴影（JSON 兜底路径，V1.2）

> V1.2 起该函数为**兜底路径**：仅当未配置 `base_map.proposed_layer`（底图提取不可用）时由 `DrawBaseMap` 第 5 步调用；绘制逻辑与提取路径完全一致（阴影 → 粗线），保证两种来源视觉统一。

```cpp
void CCreatePlanView::DrawProposedBuildings(const cJSON* arr, const ShadowParam& sp)
{
    if (CUtils::EnsureLayer(kProposedLayer).isNull()) {
        CUtils::acutPrintf(_T("[CAD ERROR] 创建图层失败：%s\n"), kProposedLayer);
        return;
    }
    if (sp.enabled && CUtils::EnsureLayer(kShadowLayer).isNull()) {
        CUtils::acutPrintf(_T("[CAD ERROR] 创建图层失败：%s\n"), kShadowLayer);

        // 1) 阴影（先画，处于下层）
        if (sp.enabled)
            DrawShadow(pts, sp);
        // 2) 轮廓（后画，处于上层）
        CUtils::AddDbPolyline(this->pModelSpace, pts, kProposedWidth, /*bClosed=*/true,
```

### 5.5 `DrawShadow()` —— 影子（SOLID 填充）

**算法**：拟建轮廓 P 整体平移 (dx, dy) 得 S，用 S 的边生成 hatch 边界（参照 `ToolDraw::create_hatch` 已验证模式），SOLID 填充，色 253，图层"底图-拟建阴影"。

```cpp
void CCreatePlanView::DrawShadow(const std::vector<AcGePoint3d>& pts, const ShadowParam& sp)
{
    if (pts.size() < 3) return;

    // 1. 平移得到影子轮廓 S
    std::vector<AcGePoint3d> s;
    s.reserve(pts.size());
    for (size_t i = 0; i < pts.size(); ++i)
        s.push_back(AcGePoint3d(pts[i].x + sp.dx, pts[i].y + sp.dy, 0.0));

    // 2. 构造 hatch（与 ToolDraw::create_hatch 同模式，已验证 2005/2007 兼容）
    AcDbHatch* pHatch = new AcDbHatch();
    pHatch->setNormal(AcGeVector3d::kZAxis);
    pHatch->setElevation(0.0);
    pHatch->setAssociative(Adesk::kFalse);

    TCHAR patternStr[64] = { 0 };
    _tcscpy_s(patternStr, _T("SOLID"));          // 2007 直接可用；2005 见 7 章兼容说明
    pHatch->setPattern(AcDbHatch::kPreDefined, patternStr);
    pHatch->setPatternScale(1.0);

    // 3. 边数组（首尾相接保证闭合）
    AcGeVoidPointerArray edgeArray;
    AcGeIntArray edgeTypes;
    for (size_t i = 0; i < s.size(); ++i) {
        AcGeLineSeg3d* seg = new AcGeLineSeg3d(s[i], s[(i + 1) % s.size()]);
        edgeArray.append(seg);
        edgeTypes.append(AcDbHatch::kLine);
    }

    // 4. 入库前设图层/颜色
    pHatch->setLayer(kShadowLayer);
    pHatch->setColorIndex(kShadowColor);

    Acad::ErrorStatus es = pHatch->appendLoop(AcDbHatch::kDefault, edgeArray, edgeTypes);
    if (es != Acad::eOk) {
        CUtils::acutPrintf(_T("[CAD ERROR] 阴影边界添加失败(错误码 %d)\n"), (int)es);
        delete pHatch;
        return;
    }
    if (pHatch->evaluateHatch() != Acad::eOk) {
        CUtils::acutPrintf(_T("[CAD WARN] 阴影填充评估失败，可能未闭合\n"));
        delete pHatch;
        return;
    }

    AcDbObjectId id;
    if (this->pModelSpace->appendAcDbEntity(id, pHatch) == Acad::eOk)
        pHatch->close();
    else
        delete pHatch;
}
```

> 内存约定：`appendLoop` 后边界对象所有权归 hatch（项目 `ToolDraw` 同款写法，不做手动 delete）。

### 5.7 两点配准：`ParseRegistration()` + `ComputeRegistration()`

**变换模型（相似变换，4 参数）**：底图 DWG 内部坐标 p（源）→ 钻孔坐标 q（目标）：
`q = T + s · R(θ) · p`，其中 T 为平移（即块插入点 insert），s 为均匀缩放 scale，θ 为旋转角 rotation。

给定两对点 P1→Q1、P2→Q2（DWG 导入后坐标变换与上式同构，直接对应 `ImportDwgAsBlock` 的 insert/scale/rotation 参数）：

```
dP = P2 - P1          （源向量）
dQ = Q2 - Q1          （目标向量）
s  = |dQ| / |dP|      （均匀缩放）
θ  = atan2(dQ.y, dQ.x) - atan2(dP.y, dP.x)   （旋转角，弧度）
T  = Q1 - s · R(θ) · P1                       （平移 = 块插入点）
```

**验证**：`T + s·R(θ)·P1 = Q1`；`T + s·R(θ)·P2 = Q1 + s·R(θ)·dP = Q1 + dQ = Q2` ✓
（`dQ = s·R(θ)·dP` 由 s、θ 定义保证）。单点模式（1 对）时 s、θ 取显式配置值，只算 `T = Q1 - s·R(θ)·P1`。

```cpp
bool CCreatePlanView::ParseRegistration(const cJSON* bm, BaseMapCfg& cfg)
{
    // registration 可选；缺省 → hasRegistration=false，走手动参数
    cJSON* reg = CUtils::GetJsonObjectItemUtf8(bm, _T("registration"));
    if (reg == NULL || !cJSON_IsObject(reg)) return false;

    cJSON* src = CUtils::GetJsonObjectItemUtf8(reg, _T("source_points"));
    cJSON* tgt = CUtils::GetJsonObjectItemUtf8(reg, _T("target_points"));
    if (src == NULL || tgt == NULL || !cJSON_IsArray(src) || !cJSON_IsArray(tgt)) {
        CUtils::acutPrintf(_T("[CAD WARN] registration 结构无效（需要 source_points/target_points 数组），回退手动对齐参数\n"));
        return false;
    }

    // 数组长度一致，且 1~2 对
    int nSrc = cJSON_GetArraySize(src), nTgt = cJSON_GetArraySize(tgt);
    if (nSrc != nTgt || nSrc < 1 || nSrc > 2) {
        CUtils::acutPrintf(_T("[CAD WARN] registration 点数不匹配或超范围（源 %d / 目标 %d，需 1~2 对），回退手动对齐参数\n"), nSrc, nTgt);
        return false;
    }

    // 逐点解析 [x, y]
    cJSON *ps = NULL, *pt = NULL;
    int i = 0;
    cJSON_ArrayForEach(ps, src) {
        cJSON* sx = CUtils::GetJsonObjectItemUtf8(ps, _T("x"));
        cJSON* sy = CUtils::GetJsonObjectItemUtf8(ps, _T("y"));
        if (sx == NULL || sy == NULL || !cJSON_IsNumber(sx) || !cJSON_IsNumber(sy)) {
            CUtils::acutPrintf(_T("[CAD WARN] registration 源点 %d 无效，回退手动对齐参数\n"), i + 1);
            return false;
        }
        cfg.srcPts[i] = AcGePoint2d(sx->valuedouble, sy->valuedouble);
        ++i;
    }
    i = 0;
    cJSON_ArrayForEach(pt, tgt) {
        cJSON* tx = CUtils::GetJsonObjectItemUtf8(pt, _T("x"));
        cJSON* ty = CUtils::GetJsonObjectItemUtf8(pt, _T("y"));
        if (tx == NULL || ty == NULL || !cJSON_IsNumber(tx) || !cJSON_IsNumber(ty)) {
            CUtils::acutPrintf(_T("[CAD WARN] registration 目标点 %d 无效，回退手动对齐参数\n"), i + 1);
            return false;
        }
        cfg.tgtPts[i] = AcGePoint2d(tx->valuedouble, ty->valuedouble);
        ++i;
    }

    cfg.regPtCount    = nSrc;
    cfg.hasRegistration = true;
    return true;
}

bool CCreatePlanView::ComputeRegistration(BaseMapCfg& cfg)
{
    if (!cfg.hasRegistration || cfg.regPtCount < 1) return false;

    // 源向量与目标向量（两点模式）
    double s = cfg.scale, theta = cfg.rotation;   // 单点模式沿用显式值
    AcGeVector2d dP, dQ;
    if (cfg.regPtCount == 2) {
        dP = cfg.srcPts[1] - cfg.srcPts[0];
        dQ = cfg.tgtPts[1] - cfg.tgtPts[0];
        double lenP = dP.length();
        if (lenP < 1e-6) {                          // 两点重合/过近 → 退化
            CUtils::acutPrintf(_T("[CAD WARN] registration 两点距离过小（%.6f），无法计算比例/旋转，回退手动对齐参数\n"), lenP);
            cfg.hasRegistration = false;
            return false;
        }
        s     = dQ.length() / lenP;                 // 均匀缩放
        theta = atan2(dQ.y, dQ.x) - atan2(dP.y, dP.x);   // 旋转角（弧度）
    }

    // 平移 T = Q1 - s·R(θ)·P1（两点/单点通用）
    double cs = cos(theta), sn = sin(theta);
    double tX = cfg.tgtPts[0].x - s * ( cs * cfg.srcPts[0].x - sn * cfg.srcPts[0].y);
    double tY = cfg.tgtPts[0].y - s * ( sn * cfg.srcPts[0].x + cs * cfg.srcPts[0].y);

    // 数值健康检查
    if (!_finite(s) || !_finite(theta) || !_finite(tX) || !_finite(tY) || s <= 0.0) {
        CUtils::acutPrintf(_T("[CAD WARN] registration 计算结果非法，回退手动对齐参数\n"));
        cfg.hasRegistration = false;
        return false;
    }

    // 回填导入参数（覆盖显式值）
    cfg.scale    = s;
    cfg.rotation = theta;
    cfg.insertX  = tX;
    cfg.insertY  = tY;
    CUtils::acutPrintf(_T("[CAD INFO] 两点配准成功：scale=%.6f rotation=%.6f rad insert=(%.3f, %.3f)\n"),
                       s, theta, tX, tY);
    return true;
}
```

> 说明：
> 1. 使用 `AcGeVector2d`（`atan2`/`length()`/`-` 均为其原生运算），也可用 `double` 手算替代，不依赖额外库；
> 2. `_finite` 为 MSVC 数学宏（`<float.h>`），2005/2007 均可用；
> 3. 配准只改**导入参数**，底图 DWG 文件与块定义内容不被修改（符合"底图只读"原则）；
> 4. 两点近似重合（`lenP` 过小）与非法数值均回退手动参数，绝不带病插入。

### 5.8 从底图提取拟建轮廓：`ExtractProposedFromBaseMap()` + `BuildRegMatrix()`

**思路（V1.2）**：拟建建筑轮廓**直接取自委托方底图 DWG**（总平面图惯例画在专门图层）。用 `AcDbDatabase::readDwgFile` 以**只读**方式打开底图文件（不导入当前图、不修改 DWG），遍历其模型空间实体，按 `cfg.proposedLayer` 过滤出**闭合多段线**，取其顶点并经配准矩阵变换到钻孔坐标系，然后复用现有 `DrawShadow` + `AddDbPolyline` 绘制——与 JSON 轮廓共用同一套绘制代码。

```cpp
// 由 insert/scale/rotation 构造变换矩阵，语义与 ImportDwgAsBlock 完全一致：
//   p → insert + R(rotation)·scale·p
AcGeMatrix3d CCreatePlanView::BuildRegMatrix(const BaseMapCfg& cfg)
{
    AcGeMatrix3d mT = AcGeMatrix3d::translation(AcGeVector3d(cfg.insertX, cfg.insertY, 0.0));
    AcGeMatrix3d mR = AcGeMatrix3d::rotation(cfg.rotation, AcGeVector3d::kZAxis);
    AcGeMatrix3d mS = AcGeMatrix3d::scaling(cfg.scale, AcGePoint3d::kOrigin);
    return mT * mR * mS;                       // 列向量语义：mT*(mR*(mS*p))
}

bool CCreatePlanView::ExtractProposedFromBaseMap(const BaseMapCfg& cfg, const ShadowParam& sp)
{
    // 0. 前置：拟建层与图层/阴影层就绪
    if (CUtils::EnsureLayer(kProposedLayer).isNull()) {
        CUtils::acutPrintf(_T("[CAD ERROR] 创建图层失败：%s\n"), kProposedLayer);
        return false;
    }
    if (sp.enabled && CUtils::EnsureLayer(kShadowLayer).isNull()) {
        CUtils::acutPrintf(_T("[CAD ERROR] 创建图层失败：%s\n"), kShadowLayer);
        return false;
    }

    // 1. 只读打开底图 DWG（不写入、不导入当前图）
    CString dwgPath = strFilePath + _T("/") + cfg.dwg;
    AcDbDatabase db(Adesk::kFalse);
    if (db.readDwgFile(dwgPath.GetString(), AcDb::kForRead, /*bAllowExclusive=*/false) != Acad::eOk) {
        CUtils::acutPrintf(_T("[CAD ERROR] 拟建轮廓读取失败（无法打开 DWG）：%s\n"), dwgPath.GetString());
        return false;
    }

    // 2. 配准矩阵（含手动参数或两点配准结果）
    AcGeMatrix3d reg = BuildRegMatrix(cfg);

    // 3. 遍历源库模型空间，按图层过滤
    AcDbBlockTable* pBt = NULL;
    if (db.getBlockTable(pBt, AcDb::kForRead) != Acad::eOk) return false;
    AcDbBlockTableRecord* pMs = NULL;
    if (pBt->getAt(ACDB_MODEL_SPACE, pMs, AcDb::kForRead) != Acad::eOk) { pBt->close(); return false; }
    pBt->close();

    int nOk = 0, nSkip = 0;
    AcDbBlockTableRecordIterator* pIt = NULL;
    pMs->newIterator(pIt);
    for (; !pIt->done(); pIt->step()) {
        AcDbEntity* pEnt = NULL;
        if (pIt->getEntity(pEnt, AcDb::kForRead) != Acad::eOk) continue;
        if (_tcscmp(pEnt->layer(), cfg.proposedLayer) == 0) {
            AcDbPolyline* pPline = AcDbPolyline::cast(pEnt);
            if (pPline != NULL && pPline->isClosed()) {
                std::vector<AcGePoint3d> pts;
                int nV = (int)pPline->numVerts();
                for (int i = 0; i < nV; ++i) {
                    AcGePoint3d pt;
                    if (pPline->getPointAt(i, pt) == Acad::eOk) {
                        pt.transformBy(reg);          // 底图坐标 → 钻孔坐标
                        pts.push_back(pt);
                    }
                }
                if (pts.size() >= 3) {
                    if (sp.enabled) DrawShadow(pts, sp);            // 阴影（下层）
                    CUtils::AddDbPolyline(this->pModelSpace, pts, kProposedWidth,
                                          /*bClosed=*/true, NULL, 256);  // 粗线轮廓（上层）
                    ++nOk;
                } else {
                    ++nSkip;
                }
            } else {
                ++nSkip;                              // 非闭合多段线/其他实体：首版跳过
            }
        }
        pEnt->close();
    }
    delete pIt;
    pMs->close();

    if (nOk == 0) {
        CUtils::acutPrintf(_T("[CAD WARN] 图层 \"%s\" 未找到闭合拟建轮廓（跳过 %d 个非闭合/其他实体），可改用 JSON proposed_buildings 兜底\n"),
                           cfg.proposedLayer.GetString(), nSkip);
        return false;
    }
    CUtils::acutPrintf(_T("[CAD INFO] 从底图提取拟建建筑：%d 栋（跳过 %d 个不支持的实体）\n"), nOk, nSkip);
    return true;
}
```

> 说明：
> 1. **只读打开**：`AcDbDatabase` 局部对象 + `readDwgFile(kForRead)`，析构自动释放；底图 DWG 文件本身不被修改；
> 2. **首版支持闭合轻量多段线**（`AcDbPolyline`，总图拟建建筑轮廓的惯例画法）；旧式 `AcDb2dPolyline`、由直线/圆弧组成的轮廓、块内实体首版**跳过**并计数告警（列入 12 章遗留项）；
> 3. 提取失败只告警，不影响底图导入与布孔；此时若配置了 `proposed_buildings`，由调用方（DrawBaseMap 第 5 步）兜底绘制；
> 4. 顶点经 `reg` 矩阵统一变换，手动 insert/scale/rotation 与两点配准两种对齐方式天然共用。

| 单点配准（1 对） | 仅计算平移，scale/rotation 取显式配置值 |
| proposed_layer 未配置 | 跳过底图提取，走 JSON `proposed_buildings` 兜底（也未配置则跳过拟建） |
| 底图 DWG 无法打开 / 无拟建图层 / 图层内无闭合多段线 | `[CAD WARN]` 提取 0 栋，回退 JSON 兜底；均无 → 跳过拟建，不影响底图与布孔 |
| 拟建图层含非闭合多段线/直线/块等实体 | 首版跳过并计数告警（`nSkip`），仅处理闭合轻量多段线 |

## 9. 网关改造：`cad_server/draw_gateway.py`（一次性无状态接口，V1.4）

> **V1.4 修订**：接口由"项目制多接口"（V1.3）**改回一次性无状态调用**——系统不记录任何项目信息（无项目编码、无项目目录、无镜像机制）。三个生成接口分开，数据随调用携带：**柱状图/剖面图携带勘探数据，平面图额外携带底图（DWG 文件上传或可访问链接二选一）+ 可选平面图配置**。参数一律放请求参数，路径不放参数。

### 9.2 底图获取（文件 / URL 二选一）

```python
def _save_base_map():
    """返回底图相对路径（相对 ARX_DIR，正斜杠）；未提供返回 None。文件/URL 二选一。"""
    f = request.files.get("base_map")
    if f and f.filename:
        safe = os.path.basename(f.filename)               # 只取文件名，防路径穿越
        if not safe.lower().endswith(".dwg"):
            raise ValueError("only .dwg allowed")
        data = f.read(DWG_MAX_BYTES + 1)
        if len(data) > DWG_MAX_BYTES:
            raise ValueError("base_map too large (>50MB)")
        os.makedirs(BASE_MAP_DIR, exist_ok=True)
        dst = os.path.join(BASE_MAP_DIR, safe)
        with open(dst, "wb") as w:
            w.write(data)
        return f"support/底图/{safe}"
    url = (request.form.get("base_map_url") or "").strip()
    if url:
        if not url.lower().startswith(("http://", "https://")):
            raise ValueError("base_map_url must be http(s)")
        with urllib.request.urlopen(url, timeout=URL_TIMEOUT) as r:
            data = r.read(DWG_MAX_BYTES + 1)
        if len(data) > DWG_MAX_BYTES:
            raise ValueError("base_map too large (>50MB)")
        name = os.path.basename(urllib.parse.urlparse(url).path) or "base_map.dwg"
        if not name.lower().endswith(".dwg"):
            raise ValueError("base_map_url must point to .dwg")
        os.makedirs(BASE_MAP_DIR, exist_ok=True)
        dst = os.path.join(BASE_MAP_DIR, name)
        with open(dst, "wb") as w:
            w.write(data)
        return f"support/底图/{name}"
    return None
```

> 说明：只取文件名（`os.path.basename`）防路径穿越；URL 仅 http/https 并限 .dwg 与大小；文件与链接均未提供时返回 None（平面图降级为仅布孔+图例）。

### 9.3 三个生成接口（分开调用，参数放请求参数）

```python
@app.route("/api/draw/column", methods=["POST"])
def draw_column():
    body = request.get_json(force=True, silent=True) or {}
    bh = body.get("borehole_data") or request.form.get("borehole_data")
    if not bh:
        return jsonify({"status": "error", "message": "missing borehole_data"}), 400
    with _lock:
        borehole_cn = _translate_borehole(bh)               # 英文 → 中文键
        _write_json(BOREHOLE_FILE, borehole_cn)             # 落盘插件标准位置
        result = _call_cad(VIEW_ROUTES["column"])           # 出图
    if body.get("auto_zoom", True):
        try: _call_cad("/ai/tool/zoom_extents", timeout=30)
        except Exception: pass
    return jsonify({"status": "success", "results": {"column": result}}), 200

@app.route("/api/draw/section", methods=["POST"])
def draw_section():
    body = request.get_json(force=True, silent=True) or {}
    bh = body.get("borehole_data") or request.form.get("borehole_data")
    if not bh:
        return jsonify({"status": "error", "message": "missing borehole_data"}), 400
    sp = body.get("section_params")
    with _lock:
        borehole_cn = _translate_borehole(bh)
        _write_json(BOREHOLE_FILE, borehole_cn)
        if sp is not None:
            _write_json(SECTION_FILE, _translate_section(sp))  # 可选剖面参数
        result = _call_cad(VIEW_ROUTES["section"])
    if body.get("auto_zoom", True):
        try: _call_cad("/ai/tool/zoom_extents", timeout=30)
        except Exception: pass
    return jsonify({"status": "success", "results": {"section": result}}), 200

@app.route("/api/draw/plan", methods=["POST"])
def draw_plan():
    body = request.get_json(force=True, silent=True) or {}
    bh = body.get("borehole_data") or request.form.get("borehole_data")
    if not bh:
        return jsonify({"status": "error", "message": "missing borehole_data"}), 400
    pb = body.get("plan_base")
    with _lock:
        try:
            dwg = _save_base_map()                          # 底图：文件或 URL，可无
        except ValueError as e:
            return jsonify({"status": "error", "message": str(e)}), 400
        borehole_cn = _translate_borehole(bh)
        _write_json(BOREHOLE_FILE, borehole_cn)
        if pb is not None:
            cfg = dict(pb)                                  # 英文 key 透传
            if dwg:
                cfg.setdefault("base_map", {})["dwg"] = dwg # 回写底图路径指向本次文件
            _write_json(PLAN_BASE_FILE, cfg)
        elif dwg:                                           # 仅有底图：写最小 plan_base
            _write_json(PLAN_BASE_FILE, {"base_map": {"dwg": dwg}})
        else:
            _remove_if_exists(PLAN_BASE_FILE)               # 无底图无配置：跳过新增能力
        result = _call_cad(VIEW_ROUTES["plan"])
    if body.get("auto_zoom", True):
        try: _call_cad("/ai/tool/zoom_extents", timeout=30)
        except Exception: pass
    return jsonify({"status": "success", "results": {"plan": result}}), 200

def _remove_if_exists(path):
    if os.path.exists(path):
        os.remove(path)
```

> 三个接口固定写死路由，语义直白；均无任何项目标识，调用结束不保留状态。`plan_base.json` 保持英文 key 原样（第 2 章字段与 C++ 解析一致），底图路径回写 `base_map.dwg` 指向本次保存的文件。`_call_cad(VIEW_ROUTES[...])`、`_translate_*`、`_lock` 均复用现有实现。

### 9.4 兼容与安全

| 项 | 设计 |
| --- | --- |
| 无状态 | 系统不保存项目目录/元信息/编码；每次调用独立落盘标准位置（覆盖上次），调用结束不保留 |
| 旧接口 | `/api/draw`（一次性全量、无项目模式）被三个独立接口取代；如需兼容保留同一实现（共用 `_write_json` / `_translate_*` / `_call_cad` / `_lock`） |
| 文件安全 | 底图 `os.path.basename` 取文件名防路径穿越；限 `.dwg` 扩展名；大小上限 50MB |
| URL 安全 | 仅 http/https（拒绝 file:// 等）；下载后校验扩展名与大小；超时/失败明确报错 |
| 并发 | 落盘与生成全程 `_lock` 串行；并发调用排队 |
| 只读原则 | 底图 DWG 与编录数据只读，生成过程不修改源文件 |
