## 1. 概述

### 1.1 系统定位

本系统面向**岩土工程勘察单位**，用于根据钻探编录数据**自动生成三类勘察成果图**：

| 成果图 | 名称 | 用途 |
| --- | --- | --- |
| 图一 | **勘探点平面布置图**（平面图） | 在场地底图上标出所有钻孔位置、编号及环境要素，直观表达勘察工作布置 |
| 图二 | **钻孔柱状图**（柱状图） | 单个钻孔的完整成果：地层分层、标贯/动探、取样、水位、坐标等，一孔一图 |
| 图三 | **工程地质剖面图**（剖面图） | 沿指定剖面线展示多个钻孔的地层对比、层位连线（含地层尖灭）、水位与标高 |

### 1.2 文档目的

本说明书用于**与客户确认需求**，涵盖：

1. 系统能做什么（功能清单）；
2. 客户需要提供什么（数据、图纸与约定）；
3. 系统交付的成果与验收标准；
4. 本次不做的事项（范围边界）。

### 1.3 术语定义

| 术语 | 说明 |
| --- | --- |
| 钻孔 / 勘探点 | 现场钻探施工点，是出图的基本数据单元 |
| 钻探编录数据 | 野外钻探的记录数据：钻孔坐标、孔口高程、深度、各层地层名称与深度、标贯/动探击数、取样、水位等 |
| 底图 | 委托方（甲方）提供的**现状总平面图 DWG 图纸**，含已有建筑、道路、地形等现状要素 |
| 拟建建筑 | 底图中待建（规划）的建筑物轮廓，区别于已有建筑；**由底图自带、随底图背景一并呈现，本版不提取、不重画** |
| 已有建筑 | 底图中已建成的建筑物，位于底图内，原样保留、整体置灰显示 |
| 底图初始化 | 理正术语，指打开底图后设定**出图比例（比例因子）、坐标转换（配准）与图层匹配**；本版实现其中"**出图比例 + 坐标对齐**"两项 |
| 出图比例 | 底图初始化时设定的**成图比例**（如 1:500、1:1000）；据此计算比例因子 `k = 1000 / N`（N 为比例分母；约定底图按 1 单位 = 1 米建模）（暂定，待客户确认），对**整体成图**统一缩放，并作为图面比例尺/标注的依据。**区别于** R7 中用于**坐标对齐**的缩放 `scale` |
| 地层尖灭 | 某一地层在相邻钻孔中消失（缺失）的现象，剖面图中需按规则连线表达 |
| 图层 | 图纸中的分层管理机制，类似"透明胶片"，便于开关、置灰与打印控制 |
| 一键生成 | 一次操作完成整张成果图的全部绘制，无需人工逐项绘制 |
| 一次性调用 | 每次出图调用独立完成，随调用提交数据与底图；系统不保存项目信息、不依赖历史数据 |
| 流程一（委托方没有底图） | 平面图的一种正式生成流程：只提交勘探数据 → 自动布孔 + 标注 + 图例；与"流程二"**地位对等**，**共用同一个"生成平面图"入口**（一步式，不拆命令） |
| 流程二（委托方有底图） | 平面图的另一种正式生成流程：提交勘探数据 + 底图（+ 出图比例/对齐配置）→ 成果叠加在底图之上 |

## 2. 系统总体说明

### 2.1 总体使用流程

#### （1）三图生成入口

```
① 调用"生成柱状图"：随调用提交钻探编录数据
② 调用"生成剖面图"：随调用提交钻探编录数据（+ 可选剖面参数）
③ 调用"生成平面图"：随调用提交钻探编录数据（+ 可选底图与配置）
```

- 三个生成功能**分开调用**：可按需要只生成其中一种图，也可全部生成；
- **每次调用独立完成、系统不保存项目信息**：同一次调用的数据即本次出图依据，不依赖历史数据；
- 同一数据可**重复调用**，图纸自动整体重绘，不会残留旧内容。

#### （2）"生成平面图"的两种委托情形（两条并列主流程）

平面图按**委托方是否提供底图**分为两条**地位对等**的主流程。两条流程**共用同一个"生成平面图"入口**——**一步式**调用，底图与配置随调用一次性提交，**不拆成两个命令**；区别仅在于**是否携带底图文件与 `plan_base` 配置**。

- **流程一（委托方没有底图）**：只提交勘探数据 → 生成平面图（自动布孔 + 标注 + 图例）；
- **流程二（委托方有底图）**：提交勘探数据 + 底图（+ 出图比例/对齐配置）→ 成果叠加在底图之上。

| 对比项 | 流程一（委托方没有底图） | 流程二（委托方有底图） |
| --- | --- | --- |
| 提交内容 | 勘探数据 | 勘探数据 + 底图（DWG 文件或可访问链接）+ 可选配置 |
| 底图导入 | 跳过 | 导入底图 DWG |
| 底图对齐 | 跳过 | 按 R7 对齐 |
| 出图比例 `plot_scale` | **适用**（缩放钻孔落点 + 图例） | **适用**（缩放底图几何 + 钻孔 + 图例） |
| 成果构成 | 钻孔（布孔 + 标注）+ 图例 | 底图 + 钻孔 + 图例 |
| 出图入口 | 同为"生成平面图"（同一命令） | 同为"生成平面图"（同一命令） |

> **出图比例说明（关键）**：`plot_scale`（成图比例）**两条流程都适用，与有无底图无关**——流程二缩放"底图几何 + 钻孔 + 图例"；流程一缩放"钻孔落点 + 图例"（底图-现状层为空，成果层照样统一缩放）。流程一**只跳过"底图导入 + 底图对齐"两步，不跳过出图比例**；仅当未配置 `plot_scale` 时才不缩放（详见 R8）。

### 2.2 运行环境

- 出图运行于 **AutoCAD 2005 / 2007**（插件方式），兼容现有单位制图环境；
- 数据上传与出图通过**系统接口**完成，使用方按接口约定提交数据即可。

## 3. 功能需求

### 3.1 数据提交与出图调用

| 编号 | 功能 | 需求描述 |
| --- | --- | --- |
| R1 | 提交勘探数据 | 生成柱状图、剖面图、平面图时随调用提交钻探编录数据（钻孔坐标、高程、地层、标贯/动探、取样、水位等） |
| R2 | 提交底图 | 生成平面图时随调用提交委托方底图：**DWG 文件上传**或**可访问链接**二选一（链接下载由网关端完成，插件端不联网）；**不提供底图时即流程一（委托方无底图）**——不用提交底图，平面图照常生成（自动布孔 + 标注 + 图例）。两条流程共用"生成平面图"这一个入口，底图与配置随调用一次性提交 |
| R3 | 提交辅助参数 | 生成剖面图时可提交剖面参数（选孔与布置）；生成平面图时可提交配置（底图对齐参数、出图比例等），均可选 |
| R4 | 一次性调用 | 三个生成接口各自独立：调用即出图，数据随调用携带，**系统不保存项目信息**，不依赖历史数据 |
| R5 | 重复调用 | 同一数据可重复调用出图，结果一致、无残留 |

### 3.2 平面图（勘探点平面布置图）

| 编号 | 功能 | 需求描述 |
| --- | --- | --- |
| R6 | 底图自动导入 | 按配置自动导入委托方底图 DWG，纳入独立图层；可整体置灰（淡化），突出钻孔等成果要素 |
| R7 | 底图自动对齐 | **默认按"底图坐标即钻孔坐标（同一坐标系、单位米）"处理，即不施加任何变换**；仅当客户声明不一致并配置两点配准（自动计算平移/旋转/缩放）或手动参数（插入位置/比例/旋转角）时，才对底图施加对齐变换；未配置任何对齐参数时按上述默认处理并在日志输出说明 |
| R8 | 出图比例 | 底图初始化时设定**出图比例**（如 1:500、1:1000）。据此计算比例因子 `k = 1000 / N`（N 为比例分母，500 表示 1:500；约定底图按 1 单位 = 1 米建模）（暂定，待客户确认），对**整体成图（底图几何 + 钻孔落点 + 成果要素）按同一比例因子、绕同一基准统一缩放**，**保证底图与钻孔不错位**（二者经同一变换）；钻孔的 X/Y 坐标标注文字仍显示真实坐标值。缩放后成果图按该比例可正确打印，并作为图面比例尺/标注的依据；未配置时按现状不施加比例缩放。**本比例两条流程均适用**（与有无底图无关）：流程二（有底图）缩放"底图几何 + 钻孔 + 图例"；流程一（无底图）缩放"钻孔落点 + 图例"（底图-现状层为空，成果层照样统一缩放）——流程一**只跳过"底图导入 + 底图对齐"两步，不跳过本比例**，仅当未配置 `plot_scale` 时才不缩放。**注**：本比例（成图比例）与 R7 中用于**坐标对齐**的缩放 `scale` 不同——后者用于消除底图与钻孔的坐标/单位差异，本比例用于**成图输出** |
| R9 | 自动布孔 | 按编录数据中的钻孔坐标自动布置钻孔符号，并自动标注钻孔编号、孔口高程、勘探深度 |
| R10 | 图例自动生成 | 自动生成图例（钻孔样例、已有/拟建建筑说明符号、剖面线等），置于图纸固定位置；建筑图例文字不含"及层数"（层数如需要由底图自带呈现，见 §5.4、§5.3） |
| R11 | 一键重生成 | 重复执行时先清空旧图再整体重绘，结果一致、无残留 |

**平面图成图顺序（视觉层次，从下到上）**：底图 → 钻孔 → 图例。

> 说明：本版**不重画底图内容**（不提取、不重画拟建轮廓），底图原样作为背景导入，因此**不存在"底图原拟建线 + 新画粗线"的轮廓双线重叠问题**。

| R22 | 底图未提供（流程一） | 未提供底图时按**流程一（委托方无底图）**正常生成平面图（自动布孔 + 标注 + 图例），无需告警、不影响其他功能；但若**配置了底图却不可用**（文件不存在 / DWG 版本过高 / 链接下载失败等），须**显式告警（告警必达，禁止静默）**告知"底图未被采用"，再按流程一继续出图 |
| R23 | 单项失败不中断 | 底图导入、出图比例、配准等任一环节失败，仅给出**显式告警（告警必达，禁止静默）**，不影响布孔与图例等其余环节 |
| R24 | 兼容现有出图 | 不配置底图与新增项时，平面图行为与现状完全一致 |

## 5. 客户需要提供的数据与约定

> 本部分是客户确认的重点：**请核对提供的资料与约定是否与实际一致。**

### 5.1 钻探编录数据

需按约定的数据格式提供（Excel/表格或系统模板均可）：

| 内容 | 说明 |
| --- | --- |
| 钻孔基本信息 | 钻孔编号、钻孔类型、孔口高程、X/Y 坐标（米）、开孔/终孔日期、稳定水位等 |
| 地层分层 | 每孔的层号、层名（如"填土-素填土"）、进尺自/至（深度，米）、颜色、状态、密实度、描述等 |
| 原位测试 | 标贯（杆长、起止深度、锤击数）、重型动探等 |
| 取样 | 取样编号、取样深度 |

### 5.2 委托方底图

| 内容 | 说明 |
| --- | --- |
| 适用流程 | **流程一（委托方没有底图）不提供本项**；**流程二（委托方有底图）提供本项**——两条流程共用"生成平面图"入口，是否携带底图即区分两流程 |
| 格式 | DWG 文件（AutoCAD 可打开） |
| 提交方式 | 随"生成平面图"调用提交：**DWG 文件上传**，或**底图文件的可访问链接**（http/https），二选一 |
| 内容 | 场地现状总平面图：已有建筑、道路、地形等现状要素 |
| 拟建建筑 | 底图中**包含拟建（规划）建筑轮廓**，由底图自带并在图面呈现（本版**不提取、不重画**，详见 §5.4） |
| 坐标系 | 底图与钻孔坐标**默认按同一坐标系、单位为米**处理（即不施加任何对齐变换）；仅当客户声明不一致并提供两组对应配准点（或手动参数）时，才按 R7 对齐 |
| 底图比例/单位 | 底图宜按真实坐标 1:1 建模（模型空间 1 单位 = 1 米）。**单位/坐标系不一致**时走**对齐参数**（两点配准或手动 `scale`，见 R7）；**出图比例**仅用于设定**成图比例**，不做单位/坐标系换算——二者分离（见 R8） |

### 5.3 需要客户确认的点

1. **底图与钻孔是否同一坐标系、单位是否同为米**（一致则无需对齐配置；不一致需提供两组对应点坐标或手动参数，见 R7）；
2. 底图是否包含**建筑层数标注**（决定 R10 图例文字是否需体现"层数"）；
3. 本次是否需要由系统设定**出图比例**（如 1:500 / 1:1000）；其语义（作用于**整体成图**统一缩放、比例因子 `k = 1000 / N`）为**暂定，待客户确认**（见 R8 说明）；
4. 底图 **DWG 版本**、是否为**扫描光栅图**（本版仅支持 DWG，光栅图不支持）；
5. 钻探编录数据是否按 5.1 结构提供（剖面图、柱状图、平面图共用该数据）。

### 5.4 底图制作要求 / 图层最小规范

> 为避免导入/对齐失败，委托方（或制图方）提供的底图建议满足以下最小规范：

| 要求 | 说明 |
| --- | --- |
| 坐标系与单位 | 底图与钻孔**同一坐标系、单位为米**；不一致时须提供两组对应配准点坐标（见 R7） |
| 底图比例/单位 | 底图按真实坐标 1:1 建模（模型空间 1 单位 = 1 米）。**单位/坐标系不一致**走**对齐参数**（两点配准 / 手动 `scale`，见 R7）；**出图比例**仅定**成图比例**，不做单位/坐标系换算，二者分离（见 R8） |
| DWG 版本 | 建议为 **AutoCAD 2004 及以下格式**，确保 AutoCAD 2005 / 2007 可打开 |
| 层数信息 | 明确定义底图是否包含建筑层数标注（影响 R10 图例文字，见 §5.3） |
| 底图类型 | 本版**仅支持 DWG**；**扫描光栅图（栅格图像）本版不支持**（如需要请另行确认） |
| 拟建/已有建筑 | 由底图自带并在图面呈现；本版**不提取、不重画**，因此**不存在轮廓双线重叠问题** |

## 6. 验收标准（客户可验证）

| # | 验收项 | 判定标准 |
| --- | --- | --- |
| 1 | 提交数据 | 生成柱状图/剖面图调用中提交钻探编录数据，出图成功 |
| 2 | 提交底图 | 生成平面图调用中以文件或链接提交底图，均能正确导入出图 |
| 3 | 生成平面图 | 出图包含：置灰底图 + 钻孔符号与编号/高程/深度标注 + 图例，层次正确（底图 → 钻孔 → 图例）；**底图内容原样呈现、未被重画** |
| 4 | 底图对齐 | 底图与钻孔坐标不一致时，配置两对对应点后自动对齐，钻孔准确落在底图相应位置；未配置对齐参数时按"同一坐标系"默认导入并在日志说明 |
| 5 | 出图比例 | 设定出图比例（如 1:500）后，**整体成图（底图几何 + 钻孔落点 + 成果要素）按同一比例因子统一缩放、底图与钻孔不错位**，成果图按该比例可正确打印，图面比例尺/标注与其一致 |
| 6 | 生成柱状图 | 每个钻孔一图，工程/钻孔信息、地层、标贯/动探、取样、花纹、制图/校对填写完整正确 |
| 7 | 生成剖面图 | 剖面布置正确，标尺与比例尺正确，地层连线含尖灭处理，花纹、水位线、标注齐全 |
| 8 | 分开调用 | 三个生成功能可独立调用，互不影响 |
| 9 | 无状态 | 连续多次调用互不干扰；每次调用只依据本次提交的数据与底图，不残留上次数据 |
| 10 | 流程一（委托方无底图） | 不提供底图与新增项时，按流程一出图：自动布孔 + 标注 + 图例，无报错；未配置 `plot_scale` 时不缩放（与现状一致） |
| 11 | 重复调用 | 同一数据重复调用，图纸一致、无残留 |
| 12 | 环境 | AutoCAD 2005 / 2007 均运行正常 |
| 13 | 边界 · 底图 DWG 版本过高 | 底图 DWG 版本超过目标 CAD（AutoCAD 2005 / 2007）可读版本时，**显式告警（告警必达）**——提示"版本过高 / 无法读取"，明确告知用户底图**未被采用**；平面图跳过底图导入并**按流程一继续出图**，不中断布孔与图例 |
| 14 | 边界 · `base_map_url` 下载失败 / 超时 | 网关端下载 `base_map_url` 失败或超时时，**显式告警（告警必达）**——给出失败原因 / 超时信息，明确告知用户底图**未被采用**；平面图**按流程一继续出图**，不中断；日志记录失败原因 |
| 15 | 边界 · 并发调用 | 并发调用时系统**串行处理**（网关侧串行 / 排队，按到达顺序执行），各调用互不干扰、不产生数据 / 图纸串扰，结果与串行调用一致 |

> **边界处理口径（告警必达，不中断）**：验收 13–15 的边界**一律不中断出图**——底图不可用时按**流程一（委托方无底图）**继续出图，但**必须显式告警（告警必达）**，明确告知用户"**底图未被采用 / 没被用上**"及原因，**禁止静默处理**；并发调用由系统串行 / 排队处理，按到达顺序执行。此口径与"流程一为与流程二对等的正式流程"一致（底图不可用即落入流程一的正常路径）；仅当后续客户明确要求"底图异常时终止"时，才改为终止语义。
