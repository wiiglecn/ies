## 1. 概述

### 1.1 系统定位

本系统面向**岩土工程勘察单位**，用于根据钻探编录数据**自动生成三类勘察成果图**：

| 成果图 | 名称 | 用途 |
| --- | --- | --- |
| 图一 | **勘探点平面布置图**（平面图） | 在场地底图上标出所有钻孔位置、编号及环境要素，直观表达勘察工作布置 |
| 图二 | **钻孔柱状图**（柱状图） | 单个钻孔的完整成果：地层分层、标贯/动探、取样、水位、坐标等，一孔一图 |
| 图三 | **工程地质剖面图**（剖面图） | 沿指定剖面线展示多个钻孔的地层对比、层位连线（含地层尖灭）、水位与标高 |

### 1.2 文档目的

本说明书用于**与客户确认需求**，涵盖：

1. 系统能做什么（功能清单）；
2. 客户需要提供什么（数据、图纸与约定）；
3. 系统交付的成果与验收标准；
4. 本次不做的事项（范围边界）。

### 1.3 术语定义

| 术语 | 说明 |
| --- | --- |
| 钻孔 / 勘探点 | 现场钻探施工点，是出图的基本数据单元 |
| 钻探编录数据 | 野外钻探的记录数据：钻孔坐标、孔口高程、深度、各层地层名称与深度、标贯/动探击数、取样、水位等 |
| 底图 | 委托方（甲方）提供的**现状总平面图 DWG 图纸**，含已有建筑、道路、地形等现状要素 |
| 拟建建筑 | 底图中待建（规划）的建筑物轮廓，区别于已有建筑，成果图上以**粗线 + 影子**突出显示 |
| 已有建筑 | 底图中已建成的建筑物，位于底图内，原样保留、整体置灰显示 |
| 地层尖灭 | 某一地层在相邻钻孔中消失（缺失）的现象，剖面图中需按规则连线表达 |
| 图层 | 图纸中的分层管理机制，类似"透明胶片"，便于开关、置灰与打印控制 |
| 一键生成 | 一次操作完成整张成果图的全部绘制，无需人工逐项绘制 |
| 一次性调用 | 每次出图调用独立完成，随调用提交数据与底图；系统不保存项目信息、不依赖历史数据 |

## 2. 系统总体说明

### 2.1 总体使用流程

```
① 调用"生成柱状图"：随调用提交钻探编录数据
② 调用"生成剖面图"：随调用提交钻探编录数据（+ 可选剖面参数）
③ 调用"生成平面图"：随调用提交钻探编录数据 + 底图（DWG 文件或可访问链接）+ 可选配置
```

- 三个生成功能**分开调用**：可按需要只生成其中一种图，也可全部生成；
- **每次调用独立完成、系统不保存项目信息**：同一次调用的数据即本次出图依据，不依赖历史数据；
- 同一数据可**重复调用**，图纸自动整体重绘，不会残留旧内容。

### 2.2 运行环境

- 出图运行于 **AutoCAD 2005 / 2007**（插件方式），兼容现有单位制图环境；
- 数据上传与出图通过**系统接口**完成，使用方按接口约定提交数据即可。

## 3. 功能需求

### 3.1 数据提交与出图调用

| 编号 | 功能 | 需求描述 |
| --- | --- | --- |
| R1 | 提交勘探数据 | 生成柱状图、剖面图、平面图时随调用提交钻探编录数据（钻孔坐标、高程、地层、标贯/动探、取样、水位等） |
| R2 | 提交底图 | 生成平面图时随调用提交委托方底图：**DWG 文件上传**或**可访问链接**二选一；未提供底图时平面图仅布孔+图例（降级） |
| R3 | 提交辅助参数 | 生成剖面图时可提交剖面参数（选孔与布置）；生成平面图时可提交配置（拟建图层、对齐参数、影子参数），均可选 |
| R4 | 一次性调用 | 三个生成接口各自独立：调用即出图，数据随调用携带，**系统不保存项目信息**，不依赖历史数据 |
| R5 | 重复调用 | 同一数据可重复调用出图，结果一致、无残留 |

### 3.2 平面图（勘探点平面布置图）

| 编号 | 功能 | 需求描述 |
| --- | --- | --- |
| R6 | 底图自动导入 | 按配置自动导入委托方底图 DWG，纳入独立图层；可整体置灰（淡化），突出钻孔等成果要素 |
| R7 | 底图自动对齐 | 底图与钻孔坐标不一致时，配置底图上两个已知点及对应的钻孔坐标点，系统**自动计算平移/旋转/缩放**对齐底图；也可手动设置插入位置、比例、旋转角 |
| R8 | 自动布孔 | 按编录数据中的钻孔坐标自动布置钻孔符号，并自动标注钻孔编号、孔口高程、勘探深度 |
| R9 | 拟建建筑绘制 | 从底图指定图层自动提取拟建建筑轮廓，以**粗线**绘制在独立图层，与已有建筑（置灰）视觉可区分；图层内无轮廓时可用轮廓坐标兜底 |
| R10 | 影子（阴影） | 每个拟建建筑自动生成**浅灰色影子**（轮廓偏移填充），位于建筑右下方；可整体开关、可调偏移量 |
| R11 | 图例自动生成 | 自动生成图例（钻孔样例、已有/拟建建筑符号、剖面线等），置于图纸固定位置 |
| R12 | 一键重生成 | 重复执行时先清空旧图再整体重绘，结果一致、无残留 |

**平面图成图顺序（视觉层次，从下到上）**：底图 → 拟建建筑影子 → 拟建建筑轮廓 → 钻孔 → 图例。

### 3.3 柱状图（钻孔柱状图）——已具备，本次不改

| 编号 | 功能 | 需求描述 |
| --- | --- | --- |
| R13 | 逐孔成图 | 每个钻孔生成一张柱状图：工程信息（工程名称、单位、地点）、钻孔信息（编号、孔口高程、坐标、孔径、日期、水位）自动填入 |
| R14 | 地层绘制 | 按编录数据逐层绘制：层序、岩土名称、层底深度与标高、层厚、土层描述（自动换行）、地层花纹填充 |
| R15 | 原位测试 | 标贯击数按杆长统计（杆长、区间、总数），重型动探以 N63.5 符号表达；取样位置与编号标注 |
| R16 | 制图人 / 校对人 | 成果图自动填入制图人与校对人签章位 |

### 3.4 剖面图（工程地质剖面图）——已具备，本次不改

| 编号 | 功能 | 需求描述 |
| --- | --- | --- |
| R17 | 剖面布置 | 按剖面参数选定钻孔组合，逐剖面成图，每个剖面独占图框 |
| R18 | 标尺与比例尺 | 按孔底最深标高与零标高自动计算高程标尺与比例尺，刻度与标高对齐（1985 国家高程基准） |
| R19 | 地层柱与连线 | 逐孔绘制地层柱状条，相邻孔同一地层自动连线；**地层尖灭**按规则处理；不同地层以不同线型/颜色区分 |
| R20 | 水位与开挖线 | 自动绘制零标高线（含水位符号）、基础底设计标高线 |
| R21 | 花纹与标注 | 地层花纹填充、层底深度(标高)标注、钻孔间距/孔深标注栏 |

### 3.5 容错与兼容

| 编号 | 功能 | 需求描述 |
| --- | --- | --- |
| R22 | 数据缺失提示 | 未上传勘探数据时，出图前明确提示"请先完成数据导入" |
| R23 | 底图缺失降级 | 未提供底图或底图文件不存在时，平面图仍可正常生成（仅布孔+图例），不报错、不影响其他功能 |
| R24 | 单项失败不中断 | 底图导入、拟建提取、配准等任一环节失败，仅给出提示，不影响布孔与图例等其余环节 |
| R25 | 兼容现有出图 | 不配置任何新增项时，平面图行为与现状完全一致 |

## 5. 客户需要提供的数据与约定

> 本部分是客户确认的重点：**请核对提供的资料与约定是否与实际一致。**

### 5.1 钻探编录数据

需按约定的数据格式提供（Excel/表格或系统模板均可）：

| 内容 | 说明 |
| --- | --- |
| 钻孔基本信息 | 钻孔编号、钻孔类型、孔口高程、X/Y 坐标（米）、开孔/终孔日期、稳定水位等 |
| 地层分层 | 每孔的层号、层名（如"填土-素填土"）、进尺自/至（深度，米）、颜色、状态、密实度、描述等 |
| 原位测试 | 标贯（杆长、起止深度、锤击数）、重型动探等 |
| 取样 | 取样编号、取样深度 |

### 5.2 委托方底图

| 内容 | 说明 |
| --- | --- |
| 格式 | DWG 文件（AutoCAD 可打开） |
| 提交方式 | 随"生成平面图"调用提交：**DWG 文件上传**，或**底图文件的可访问链接**（http/https），二选一 |
| 内容 | 场地现状总平面图：已有建筑、道路、地形等现状要素 |
| 拟建建筑 | 底图中**已包含拟建（规划）建筑轮廓**，画在专门图层 |
| 坐标系 | 与钻孔坐标原则上同一坐标系、单位为米（不一致时按 R7 对齐） |

### 5.3 需要客户确认的点

1. **拟建建筑轮廓所在图层名**（例如阳光幸福里项目为"0-规划建筑"）；该图层中**是否全部为拟建建筑**（如有已有建筑在同一图层，请另行说明，以免误判）；
2. 底图坐标系与钻孔坐标是否一致（一致则无需对齐配置）；
3. 钻探编录数据是否按 5.1 结构提供（剖面图、柱状图、平面图共用该数据）。

## 6. 验收标准（客户可验证）

| # | 验收项 | 判定标准 |
| --- | --- | --- |
| 1 | 提交数据 | 生成柱状图/剖面图调用中提交钻探编录数据，出图成功 |
| 2 | 提交底图 | 生成平面图调用中以文件或链接提交底图，均能正确导入出图 |
| 3 | 生成平面图 | 出图包含：置灰底图 + 拟建建筑粗线轮廓与浅灰影子 + 钻孔符号与编号/高程/深度标注 + 图例，层次正确 |
| 4 | 底图对齐 | 底图与钻孔坐标不一致时，配置两对对应点后自动对齐，钻孔准确落在底图相应位置 |
| 5 | 拟建建筑 | 底图指定图层内的建筑轮廓被自动提取，粗线绘制，与底图位置形状吻合 |
| 6 | 影子 | 拟建建筑右下方有浅灰影子，可开关、可调偏移 |
| 7 | 生成柱状图 | 每个钻孔一图，工程/钻孔信息、地层、标贯/动探、取样、花纹、制图/校对填写完整正确 |
| 8 | 生成剖面图 | 剖面布置正确，标尺与比例尺正确，地层连线含尖灭处理，花纹、水位线、标注齐全 |
| 9 | 分开调用 | 三个生成功能可独立调用，互不影响 |
| 10 | 无状态 | 连续多次调用互不干扰；每次调用只依据本次提交的数据与底图，不残留上次数据 |
| 11 | 兼容现状 | 不配置底图与新增项时，平面图仅布孔+图例，与现状一致 |
| 12 | 重复调用 | 同一数据重复调用，图纸一致、无残留 |
| 13 | 环境 | AutoCAD 2005 / 2007 均运行正常 |
