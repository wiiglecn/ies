## 1. 决策落地说明

### 1.1 D-A：接口 `borehole_data` 只收二维数组 JSON

**现状**（决策前）

- 接口文档 V1.1 §9 / `cad_server/API.md` v2.1 §4 把 `borehole_data` 定义为**结构化英文 JSON**：`{ "ZK1": { hole_no, x, y, elevation, depth, layers[] } }`；
- 实际调用方（业务系统 / `cad_client/excel_to_json.py`）只产出**二维数组 JSON**：`{ "ZK1": [[row1], [row2], ...] }`；
- 两端格式不同，临时在 `cad_client` 端塞了个 406 行的 `excel_to_borehole_data.py` 做适配——但这是**错位**：把网关内部字段结构泄漏给每个调用方，N 个调用方就要各自实现一遍，且本端实现还会与未来网关实现分歧。

**决策后**（D-A）

- 接口 `borehole_data` **只收**二维数组 JSON；
- 结构化英文 JSON 作为网关内部表示（`_normalize_borehole` 输出），**不再**作为入参格式；
- 形态 A（ARX 内嵌 `:7100`）保留结构化输入作**遗留兼容**（详见 §4）。

**影响面**

| 影响 | 处理 |
| --- | --- |
| 业务系统调用方 | 简化：调用方只需把 xlsx 转二维数组 JSON 即可提交，无需再关心 borehole_data 字段语义 |
| 接口文档 §9 | 重写：原 §9 结构化格式整章替换为 §2 二维数组格式规范（影响面清单见 §6 第 1 行） |
| `cad_server/API.md` §4 | 重写（影响面见 §6 第 2 行） |
| `cad_server/draw_gateway.py` | 新增 `_normalize_borehole()`；`_translate_borehole()` 不动（仅是其输入从"调用方来"变为"网关内部来"） |

### 1.2 D-B：转换逻辑落在 Python 网关（形态 B）

**决策后**（D-B）

- 新增函数 `cad_server/draw_gateway.py::_normalize_borehole(raw)`，把二维数组 JSON 转为**英文键结构化 JSON**（即 `_translate_borehole()` 当前输入格式）；
- 转换链：`二维数组 → (_normalize_borehole) → 英文键结构化 → (_translate_borehole 英译中) → 中文键结构化 → 落盘 ARX 端 project/钻探编录表.json`；
- **关键约束**：`_normalize_borehole` 输出必须是**英文键**结构化（不是中文键），否则 `_translate_borehole` 的英译中映射对不上，落盘中文键与 ARX 端期望不一致（41s 教训）；
- 网关内部单一转换实现，cad_client 不再实现转换（详见 §5）。

## 2. 二维数组 JSON 输入格式规范

### 2.1 顶层结构

```json
{
  "<孔号 1>": [[row_0], [row_1], [row_2], ...],
  "<孔号 2>": [[row_0], [row_1], [row_2], ...],
  ...
}
```

| 约束 | 规则 |
| --- | --- |
| 顶层 | object，顶层 key = 孔号（字符串，**原样保留**——不规范化、不强转大写） |
| 每个 value | list[list[any]]——每行是一个 list，列宽不固定（按 xlsx 实际列数） |
| 行数 | 每孔 ≥ 7 行（最少含基本信息 4 行 + 表头 1 行 + 字段表头 1 行 + 至少 1 个地层） |
| 单元格 | string / number / null 三种；数字格按 JS Number（int / float）解析；空缺为 `null` |
| 字符编码 | UTF-8，JSON 无 BOM |
| 顺序 | 顶层 key 顺序**不要求**；地层行顺序按 zk 内部 row 顺序处理 |

### 2.2 单孔二维数组的行义（基于 cad_client 阳光幸福里-钻探编录表.json 真实 ZK1 反推）

> **本节为**"行义"**单孔模板定稿**：基于真实 11+ 行模板反推行偏移常量，所有"中文标签识别 + 标签位置列偏移"以此为准。

### 2.4 地层列表组装规则（地层 / 取样 / 原位测试三段）

按 §2.3 行 13~28，地层行 `r` 从 `ROW_STRATA_START (= 7)` 开始扫描，到 `len(rows) - 1` 结束：

1. **空行跳过**：`row` 中所有单元格均为 `null` / 空字符串 / 仅空白 → 跳过；
2. **终止行跳过**：col 3 == "终孔" → 跳过；
3. **无效进尺跳过**：`s_from == null and s_to == null` → 跳过（防御非法行）；
4. **地层基本段**（必填+可选）：`layer_id, from, to, name, color, state, density, moisture, description` —— 即使空字符串也输出（**保持字段存在性**），仅 `null` 才省略；
5. **取样段**：仅当 `sample.no` 或 `sample.depth` **任一非空**时输出 `sample: { no, depth }`；
6. **原位测试段**：仅当 `test.type` 或 `test.from/to/rod_length/hits` **任一非空**时输出 `test: { type, from, to, rod_length, hits }`；
7. **结构（与接口 V1.1 §9.3.1 / §9.3.2 对齐）**：

### 2.5 容错规则

| 异常 | 处理 | HTTP 状态 |
| --- | --- | --- |
| 顶层不是 object | `borehole_data must be a JSON object` | **400** |
| 顶层为空 object（无孔） | 静默跳过（落空 borehole_data.json）；日志 `[WARN] no holes in borehole_data` | 200 |

### 3.1 新增函数 `_normalize_borehole(raw) -> dict`

**签名**

```python
def _normalize_borehole(raw: dict[str, list[list[Any]]]) -> dict[str, dict[str, Any]]:
    """二维数组 borehole_data JSON → 英文键结构化 borehole_data JSON。

    输入格式：见 §2.1 顶层结构（{孔号: 二维数组}）。
    输出格式：见接口文档 V1.1 §9 结构化英文 JSON（_translate_borehole 当前输入格式）。
    异常：ValueError（rows < 7 / 关键标签缺失 / hole_no 与 key 不一致 / 必填字段非数字）。
    """
```

**输入契约**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `raw` | `dict[str, list[list[Any]]]` | 是 | 二维数组 borehole_data；顶层 key = 孔号 |

**输出契约**

| 返回 | 类型 | 说明 |
| --- | --- | --- |
| `dict[str, dict]` | `{hole_no: {hole_no, x, y, elevation, depth, layers[]}}` | 英文键结构化 JSON；顶层 key = 孔号（与 raw 一致） |

**伪代码（关键路径）**

```python
def _normalize_borehole(raw):
    if not isinstance(raw, dict):
        raise ValueError("borehole_data must be a JSON object")
    out = {}
    for zk_id, rows in raw.items():
        if not isinstance(rows, list):
            raise ValueError(f"borehole_data['{zk_id}']: 必须为 list（实际 {type(rows).__name__}）")
        if len(rows) < ROW_STRATA_START:
            raise ValueError(f"borehole_data['{zk_id}']: 行数 {len(rows)} < {ROW_STRATA_START}，模板异常")
        # ---- 标签校验（防止 xlsx 模板换版） ----
        if _get_str(rows[ROW_INFO_3], 0) != "钻孔编号":
            raise ValueError(f"borehole_data['{zk_id}']: row {ROW_INFO_3} col 0 标签缺失（期望'钻孔编号'）")
        if _get_str(rows[ROW_INFO_3], 3) != "X坐标（m）":
            raise ValueError(f"borehole_data['{zk_id}']: row {ROW_INFO_3} col 3 标签缺失（期望'X坐标（m）'）")
        if _get_str(rows[ROW_INFO_3], 8) != "Y坐标（m）":
            raise ValueError(f"borehole_data['{zk_id}']: row {ROW_INFO_3} col 8 标签缺失（期望'Y坐标（m）'）")
        # ---- 基础信息 ----
        hole_no = _get_str(rows[ROW_INFO_3], COL_HOLE_NO)
        if hole_no != zk_id:
            raise ValueError(f"borehole_data['{zk_id}']: row {ROW_INFO_3} col 1 '{hole_no}' 与 key '{zk_id}' 不一致")
        elevation = _get_num_required(rows[ROW_INFO_1], COL_ELEVATION, "孔口高程(m)", zk_id)
        depth     = _get_num_required(rows[ROW_INFO_1], COL_DEPTH,    "终孔深度(m)", zk_id)
        x_meas    = _get_num_required(rows[ROW_INFO_3], COL_X_SURVEY, "X坐标(m)", zk_id)
        y_meas    = _get_num_required(rows[ROW_INFO_3], COL_Y_SURVEY, "Y坐标(m)", zk_id)
        # ⚠️ X/Y 交换：测量学 X=北 → JSON y；测量学 Y=东 → JSON x
        x_cad, y_cad = y_meas, x_meas
        # ---- 地层列表 ----
        layers = []
        for ri in range(ROW_STRATA_START, len(rows)):
            row = rows[ri]
            if not any(v is not None and str(v).strip() for v in row):
                continue
            if _get_str(row, 3) == "终孔":
                continue
            s_from = _get_num(row, COL_STRATA_FROM)
            s_to   = _get_num(row, COL_STRATA_TO)
            if s_from is None and s_to is None:
                continue
            layer = {
                "layer_id":    _get_str(row, COL_STRATA_ID),
                "from":        s_from,
                "to":          s_to,
                "name":        _get_str(row, COL_STRATA_NAME),
                "color":       _get_str(row, COL_STRATA_COLOR),
                "state":       _get_str(row, COL_STRATA_STATE),
                "density":     _get_str(row, COL_STRATA_DENS),
                "moisture":    _get_str(row, COL_STRATA_MOIST),
                "description": _get_str(row, COL_STRATA_DESC),
            }
            # 取样段
            sample_no    = _get_str(row, COL_SAMPLE_NO)
            sample_depth = _get_str(row, COL_SAMPLE_DEPTH)
            if sample_no or sample_depth:
                layer["sample"] = {"no": sample_no, "depth": sample_depth}
            # 原位测试段
            test_type  = _get_str(row, COL_TEST_TYPE)
            test_from  = _get_str(row, COL_TEST_FROM)   # 字符串口径
            test_to    = _get_str(row, COL_TEST_TO)
            test_rod   = _get_str(row, COL_TEST_ROD)
            test_hits  = _get_str(row, COL_TEST_HITS)
            if test_type or test_from or test_to or test_rod or test_hits:
                layer["test"] = {
                    "type": test_type, "from": test_from, "to": test_to,
                    "rod_length": test_rod, "hits": test_hits,
                }
            layers.append(layer)
        # ---- 组装 borehole_data 节点 ----
        node = {
            "hole_no":    hole_no,
            "x":          x_cad,
            "y":          y_cad,
            "elevation":  elevation,
            "depth":      depth,
            "hole_type":  _get_str(rows[ROW_INFO_1], COL_HOLE_TYPE),
            "project_name": _get_str(rows[ROW_INFO_1], COL_PROJ_NAME),
            "site":       _get_str(rows[ROW_INFO_2], COL_PROJ_LOC),
            "date_start": _get_str(rows[ROW_INFO_2], COL_DATE_START),
            "date_end":   _get_str(rows[ROW_INFO_3], COL_DATE_END),
            "water_level_initial": _get_num_or_str(rows[ROW_INFO_2], COL_WATER_INIT),
            "water_level_stable":  _get_num_or_str(rows[ROW_INFO_3], COL_WATER_STABLE),
            "layers":     layers,
        }
        out[zk_id] = node
    return out
```

**辅助函数（伪代码）**

```python
def _get_str(row, col):
    if col >= len(row): return ""
    v = row[col]
    return "" if v is None else str(v).strip()

def _get_num(row, col):
    """取数字（None / 空 / 非数字返回 None）。"""
    if col >= len(row): return None
    v = row[col]
    if v is None or v == "" or (isinstance(v, str) and v.strip() == ""):
        return None
    try: return float(v) if isinstance(v, str) and "." in v else int(v) if isinstance(v, str) and v.isdigit() else v
    except (TypeError, ValueError): return None

def _get_num_required(row, col, field_name, zk_id):
    v = _get_num(row, col)
    if v is None:
        raise ValueError(f"borehole_data['{zk_id}']: 字段 {field_name} 非数字或缺失")
    return v

def _get_num_or_str(row, col):
    """水位字段：数字保留 float，空字符串/null 保留为 None。"""
    if col >= len(row): return None
    v = row[col]
    if v is None or (isinstance(v, str) and v.strip() == ""): return None
    return v  # 不强转，保留 number 或 string 原样
```

## 4. 两形态契约边界处理

### 4.1 形态 B（网关 `cad_server/draw_gateway.py` · 主路径）

- **入参**：`borehole_data` = 二维数组 JSON（§2.1）；
- **网关内部**：`raw → _normalize_borehole → 英文结构化 → _translate_borehole → 中文结构化 → 落盘`project/钻探编录表.json`；
- **接口契约**：接口文档 V1.1 §9 **整章重写**为 §2（本设计）；接口文档 §9.1 / §9.2 / §9.3 / §9.4 / §9.5 节号保留但内容全部替换为二维数组 JSON 规范。

### 4.2 形态 A（ARX 内嵌 `:7100` · 遗留兼容）

> **关键判断**：形态 A 是 ARX 内嵌 HTTP，无独立网关；调用方直连 `:7100`。D-A 决策**作用域为网关（形态 B）**，形态 A **不在 D-A 决策范围**——因为形态 A 的"网关内部转换"不存在于客户端，业务系统直连 ARX。

**建议处理（明确推荐）**：

| 项 | 建议 | 理由 |
| --- | --- | --- |
| 形态 A 接口契约（`cad_server/API.md` §4） | **保留结构化英文 JSON 作为形态 A 入参**；状态从"✅ 已实现"翻为"⚠️ 遗留 · 推荐迁移至形态 B" | 形态 A 无独立网关，调用方必须自己保证结构化输入正确性；强行下沉到 ARX 内嵌服务会与现有 C++ `TranslateKeys` 逻辑冲突（41s 教训） |
| 形态 A §9 在接口文档中 | 标注"**形态 A 遗留格式**，新接入请走形态 B"；与 §9 重写并行；提供"形态 B → 形态 A"的迁移示例（调用方侧加 `_normalize_borehole` 等价实现） | 避免一次性破坏现存形态 A 集成；同时推动迁移 |
| 形态 A §9 在 `cad_server/API.md` | 保持现状不动 | 形态 A 现状代码位于 ARX 内部；`API.md` 描述的是已存在的 `:7100` 协议 |
| 形态 A 终态 | **下一里程碑**（用户拍板后）从 `cad_server/API.md` 中将 §4 整章迁移至"遗留附录"或删除 | 不在本增量设计范围 |

### 4.3 不混用的硬约束

| 边界 | 规则 |
| --- | --- |
| 形态 A 调用方 | **不得**用形态 B 的二维数组 JSON 调 `:7100`；混用会因 `borehole_data["ZK1"]["hole_no"]` 取不到而崩溃 |
| 形态 B 调用方 | **不得**用形态 A 的结构化 JSON 调网关；`_normalize_borehole` 会因行数检查失败返 400（§2.5） |
| 网关 `_translate_borehole` | 形态 B 路径下**必须**接收 `_normalize_borehole` 输出（英文键），不能接收二维数组或中文键 |

## 5. cad_client 脚本去留

### 5.1 建议：**保留为离线校验工具**，标注 deprecated

**理由**

| 维度 | 保留的好处 | 删除的坏处（若删） |
| --- | --- | --- |
| 离线对账 | 业务系统集成测试时，可用 `excel_to_borehole_data.py` + `diff_vs_arx()` 与 ARX 端 `project/钻探编录表.json` 核对字段正确性（X/Y 是否装反、终孔深度是否一致） | 删除后，业务系统回归测试失去离线对账抓手；底图/钻孔错位类问题只能等到出图阶段才能发现 |
| 单一转换实现 | `excel_to_borehole_data.py:convert_sheet_to_borehole()` 的核心逻辑与本设计 `_normalize_borehole` **等价**（二维数组→结构化）；本设计 §3.1 与该函数对照即可 | （不适用） |
| 历史兼容 | 一些存量脚本（如 `阳光幸福里项目/3.导出的施工勘探数据/` 自动化流程）可能仍依赖该 CLI 输出 `_borehole.json` 拷到 ARX 端 | 删除会破坏既有离线流程；需要留过渡期 |
| 文档引用 | 主理人临时方案 `cad_client/excel_to_borehole_data.py` 已被 `cad_client/excel_to_borehole_data.py:113-117` 引用为"对账报告"——保留可让外部对接方按现有模式继续 | 引用断裂 |

**操作建议**

1. **保留文件**：不删除 `cad_client/excel_to_borehole_data.py`；
2. **添加 deprecated 标识**（代码首部 docstring 顶部）：
   ```
   ⚠️ DEPRECATED：本脚本的"二维数组→结构化"转换逻辑已下沉至 cad_server/draw_gateway.py::_normalize_borehole。
   业务系统集成时，请勿再用本脚本生成 borehole_data JSON 提交网关（应直接提交二维数组 JSON）。
   本脚本仅作为【离线校验工具】，用于业务系统集成测试阶段与 cad/exploration/Debug/project/钻探编录表.json 对账。
   ```
3. **列偏移常量勘误**（顺手做小修复，不属本任务，标注建议）：`excel_to_borehole_data.py:164-169` 的 `COL_TEST_HITS/COL_TEST_CORRECTED` 与真实 xlsx 不符——V1.7 勘误见 §2.2 末段；
4. **新增 CLI 选项 `--validate-only`**（建议，不阻塞）：本脚本默认行为改为仅做"xlsx → 二维数组 → 结构化"对账，**不**自动覆盖 ARX 端文件；覆盖需显式 `--write-arx`。

### 5.2 与"单一转换实现"原则的关系

> **用户拍板原则**：转换层只在一处实现（cad_server 网关），不在 cad_client / ARX / 其他位置重复。

**对照**

| 实现 | 是否违反原则 |
| --- | --- |
| `cad_server/draw_gateway.py::_normalize_borehole`（新增） | **唯一**正式实现 |
| `cad_client/excel_to_borehole_data.py:convert_sheet_to_borehole`（保留为离线校验工具） | **不违反**——明确标注 deprecated；不接入业务系统主链路；仅做对账校验 |
| `cad_server/API.md` §4（形态 A 描述结构化输入） | **不违反**——形态 A 是 ARX 内嵌服务，转换在调用方侧（不在网关/客户端实现库）；业务系统选择形态 A 时需自行保证结构化输入 |
| ARX 端 C++ `TranslateKeys` | **不违反**——是英译中键（`_translate_borehole` 等价物），不是二维数组→结构化的转换 |
